`Would like` — ввічлива форма «хотіти». Звучить м'якше, ніж `want`.

## Форми

| | Схема | Приклад |
| --- | --- | --- |
| Ствердження | I **would (I'd) like** + іменник / to + V | I'd like a coffee. / I'd like **to book** a table. |
| Заперечення | I **wouldn't like** … | I wouldn't like to be late. |
| Питання | **Would** you **like** …? | **Would** you **like** some tea? |

## Пропозиція

- ***Would you like** a drink?* — Yes, please. / No, thank you.
- ***Would you like to** come with us?* — I'd love to.

## Прохання

- ***I'd like** the fish, please.* (у ресторані)
- ***I'd like to** speak to the manager.*

## Would like чи like?

| Would like | Like |
| --- | --- |
| Хочу **зараз** / конкретно | Подобається **загалом** |
| **I'd like** some water. | **I like** water. |
| **Would you like** to dance? (запрошення) | **Do you like** dancing? (уподобання) |

> Після `would like to` — інфінітив; після `like` (уподобання) можливі `-ing` і `to`. Порівняйте: *Would you like to swim?* — *Do you like swimming?*
