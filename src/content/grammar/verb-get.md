`Get` — одне з найуживаніших дієслів, значення залежить від того, що після нього.

## Основні значення

| Значення | Приклад |
| --- | --- |
| **отримувати** | I **got** a letter. — Я отримав листа. |
| **купувати, діставати** | Can you **get** some milk? |
| **приносити** | **Get** me a glass of water. |
| **ставати** (get + прикметник) | It's **getting** dark. / She **got** tired. |
| **добиратися, прибувати** | When did you **get** home? |
| **розуміти** (розм.) | I don't **get** it. |
| **мати нагоду** (get to + V) | We **got to see** the show. — Нам пощастило побачити шоу. |

## Get + прикметник = ставати

- *get tired / angry / cold / better / old / lost / married*
- *It **gets** cold in winter.* / *Let's go before it **gets** late.*

## Get + предмет + V3

Послуга чи подія (розмовний варіант `have something done`):

- *I **got** my car **repaired**.* / *She **got** her hair **cut**.*

## Get як пасив

- *He **got** fired.* — Його звільнили. *(розмовно, для подій)*
- *They **got** married in June.*

## Часті фразові дієслова з get

| Вираз | Значення |
| --- | --- |
| get up | вставати |
| get on (with) | ладнати; сідати (в транспорт) |
| get off | виходити (з транспорту) |
| get along (with) | ладнати |
| get over | оговтатися |
| get back | повертатися |
| get away | втекти |
| get through | пройти, дозвонитися |
| get in / out (of) | сідати / виходити (з авто) |
| get used to | звикати |

## Get + to-інфінітив і -ing

- **get to** + V — «мати нагоду»: *We **got to meet** the actors.*
- **get** + особа + **to** + V — «умовити, домогтися»: *I **got him to help** me.*
- **get going / get moving** — «рушати»: *Let's **get going**.*

## Get у переходах станів

| Вираз | Значення |
| --- | --- |
| get ready / dressed / changed | приготуватися / одягнутися / перевдягнутися |
| get lost / stuck | заблукати / застрягти |
| get better / worse | покращуватися / погіршуватися |
| get rid of | позбутися |
| get in touch with | зв'язатися |
| get the hang of | зрозуміти, як це робиться |

## Have got і get

`Have got` = «мати» (теперішній час); `got` — минуле від `get` («отримав»): *I'**ve got** a car* (маю) — *I **got** a car last year* (купив).

## Типові помилки

- ✗ *It's getting to be dark.* (зайве) → ✓ *It's **getting dark**.*
- ✗ *I got repaired my car.* → ✓ *I got **my car repaired**.*
- ✗ *We got married with each other.* → ✓ *We **got married**.* / *She **got married to** Tom.*
- ✗ *How did you get to home?* → ✓ *How did you **get home**?*
- ✗ *I got him help me.* → ✓ *I got him **to help** me.*
- ✗ *We need to get rid from these boxes.* → ✓ *We need to get rid **of** these boxes.*

Див. «Used to, would, be used to, get used to» та «Passive: it is said that…, have something done».
