`Get` — одне з найуживаніших дієслів, значення залежить від того, що після нього.

## Основні значення

| Значення | Приклад |
| --- | --- |
| **отримувати** | I **got** a letter. — Я отримав листа. |
| **купувати, діставати** | Can you **get** some milk? |
| **приносити** | **Get** me a glass of water. |
| **ставати** (get + прикметник) | It's **getting** dark. / She **got** tired. |
| **добиратися, прибувати** | When did you **get** home? |
| **розуміти** (розм.) | I don't **get** it. |
| **дозволяти собі, встигати** | We **got** to see the show. |

## Get + прикметник = ставати

- *get tired / angry / cold / better / old / lost / married*
- *It **gets** cold in winter.* / *Let's go before it **gets** late.*

## Get + предмет + V3

Послуга чи подія (розмовний варіант `have something done`):

- *I **got** my car **repaired**.* / *She **got** her hair **cut**.*

## Get як пасив

- *He **got** fired.* — Його звільнили. *(розмовно, для подій)*
- *They **got** married in June.*

## Часті фразові дієслова з get

| Вираз | Значення |
| --- | --- |
| get up | вставати |
| get on (with) | ладнати; сідати (в транспорт) |
| get off | виходити (з транспорту) |
| get along (with) | ладнати |
| get over | оговтатися |
| get back | повертатися |
| get away | втекти |
| get through | пройти, дозвонитися |
| get in / out (of) | сідати / виходити (з авто) |
| get used to | звикати |

Див. «Used to, would, be used to, get used to» та «Passive: it is said that…, have something done».
