`Look`, `sound`, `feel`, `smell`, `taste` описують, **яке враження** справляє щось. Після них — **прикметник** (а не прислівник).

## Схеми

| Схема | Приклад |
| --- | --- |
| **дієслово + adjective** | She **looks tired**. / It **sounds great**. / The soup **tastes good**. |
| **дієслово + like + іменник** | It **looks like** a dog. / He **sounds like** his father. |
| **дієслово + as if / as though + речення** | It **looks as if** it's going to rain. |

- *This cake **smells delicious**.* (не *deliciously*)
- *I **feel** sick.* / *The fabric **feels** soft.*

## Відрізняйте: стан і дія

| Стан (враження) | Дія (навмисно) |
| --- | --- |
| The soup **tastes** salty. | She **is tasting** the soup. |
| The flower **smells** nice. | He **smelled** the flower. |
| It **looks** old. | **Look at** that! |
| It **sounds** interesting. | **Listen to** this! |

- **see / hear** — сприймаємо без наміру; **look at / listen to** — навмисно.
- Як дієслова стану, `taste`, `smell`, `sound` у Continuous не вживаються. Див. «Stative verbs і dynamic verbs».

## Схожі за змістом

`Seem` і `appear` працюють подібно: *She **seems** happy.* Див. «Seem — здаватися».

## Типові помилки

- ✗ *It smells deliciously.* → ✓ *It smells **delicious**.*
- ✗ *You look like tired.* → ✓ *You look **tired**.* (like — перед іменником)
- ✗ *It sounds like great.* → ✓ *It sounds **great**.* (перед прикметником — без like)
- ✗ *The soup is tasting salty.* → ✓ *The soup **tastes** salty.*
