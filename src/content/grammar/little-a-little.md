Артикль *a* тут повністю змінює настрій. **a few / a little** — «кілька, трохи» (є, і цього досить). **few / little** без артикля — «мало, майже немає» (бракує). Ширше про кількісні слова — у «Quantifiers: much, many, few, little, some, any, all, both, either, neither».

## Лічильні: few, a few

- ***A few** friends came to help.* — кілька друзів, добре.
- ***Few** people understood the joke.* — мало хто, майже ніхто.
- ***Quite a few*** = досить багато: *Quite a few students failed.*

## Нелічильні: little, a little

- *There's **a little** milk left — enough for coffee.* — трохи є.
- *There's **little** hope now.* — надії майже немає.
- *I speak **a little** French.*

## Very, only, so

- ***very few / very little*** — дуже мало: *Very few people know this.*
- ***only a few / only a little*** — лише кілька, лише трохи (з артиклем!): *I have **only a few** minutes.*
- *few* і *little* без артикля звучать книжно; у розмові частіше *not many / not much*: *Not many people came.*

## A little як прислівник

*a little* + прикметник у порівняльному ступені чи дієслово — «трохи»: *I feel **a little** better.* / *Can you move **a little**?*

## Як вибрати

1. Лічильні в множині — *few / a few*; нелічильні — *little / a little*.
2. Є, і цього досить — з артиклем: *a few, a little*.
3. Бракує, майже немає — без артикля: *few, little* (у розмові *not many / not much*).
4. «Лише кілька» — *only a few*; «досить багато» — *quite a few*.

## Пастки перекладу

- «У мене є трохи грошей» — *I have **a little** money*.
- «Мало хто знає» — ***Few** people know*.
- «Кілька хвилин» — ***a few** minutes*, не *a little minutes*.

## Типові помилки

- ✗ *I've got a little friends in this city, so I'm never lonely.* → ✓ *I've got **a few** friends in this city, so I'm never lonely.*
- ✗ *Can I have a few water, please?* → ✓ *Can I have **a little** water, please?*
- ✗ *I only have few minutes, so let's be quick.* → ✓ *I only have **a few** minutes, so let's be quick.*
- ✗ *There's few milk in the fridge, so buy some.* → ✓ *There's **little** milk in the fridge, so buy some.*
