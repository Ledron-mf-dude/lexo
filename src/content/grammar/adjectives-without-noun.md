Прикметник із `the` може означати **групу людей** — без іменника.

## The + adjective = група

| Приклад | Значення |
| --- | --- |
| **the rich / the poor** | багаті / бідні |
| **the young / the old** | молодь / старші |
| **the elderly** | літні люди |
| **the sick / the injured** | хворі / поранені |
| **the unemployed** | безробітні |
| **the blind / the deaf** | незрячі / глухі |
| **the homeless** | бездомні |

Дієслово — **у множині**: ***The rich are** not always happy.* / ***The young need** support.*

## Національності

| Національність | Група |
| --- | --- |
| the **British**, the **French**, the **Dutch**, the **Spanish**, the **Irish** | **the British are** polite |
| **Italian, German, Russian** — мають форму іменника | **Italians** love pasta |

## Абстрактні поняття

Також означають **явище** (однина):

- ***The unknown** scares people.* — невідоме.
- *He wants to do **the impossible**.*
- ***The best** is yet to come.*

## Не плутайте

| Група людей | Один чоловік |
| --- | --- |
| **The poor** need help. | The **poor man** needs help. |
| **The rich** pay more taxes. | The **rich woman** lives here. |

Для одного — потрібен іменник: *a rich **man***, не *a rich*.

## Заміна іменника: one, ones

Щоб не повторювати іменник: *I like the **red** one.* / *the **big** ones*. Див. «Ellipsis and substitution».
