## Куди йдемо

| Конструкція | Приклад |
| --- | --- |
| **go to** + місце | I **go to** work by bus. |
| **go** + home / abroad / upstairs / there | She **went home**. (без `to`) |
| **go on holiday / a trip** | We **go on holiday** every summer. |
| **go by** + транспорт | I **go by** train. (але *on foot* — пішки) |

## Go + -ing (активності)

Для спорту й дозвілля:

- **go swimming, go running, go shopping, go fishing, go skiing, go dancing**
- *We **went shopping** yesterday.*

## Go for + іменник

- **go for a walk / a run / a swim / a drink**
- *Let's **go for a walk**.*

## Go + прикметник (змінюватися)

- **go bad** (псуватися), **go mad**, **go pale**, **go blind**, **go wrong**.
- *The milk **went bad**.* / *Everything **went wrong**.*

## Been чи gone

| | Значення |
| --- | --- |
| **has gone to** | пішла і ще там |
| **has been to** | була і повернулася |

- *She **has gone to** London.* (зараз у Лондоні)
- *She **has been to** London.* (колись побувала)

## Поширені вирази

| Вираз | Значення |
| --- | --- |
| go ahead | продовжуй, давай |
| go on | продовжувати; відбуватися |
| go out | виходити, гуляти |
| go away | піти, поїхати |
| go up / down | зростати / знижуватися |
| go off | вибухнути; зіпсуватися; спрацювати (будильник) |
| go through | пройти (випробування); переглядати |

## Go чи come?

- **go** — рух **від** мовця або туди, де його немає: *Let's **go** to the park.*
- **come** — рух **до** мовця або туди, де буде співрозмовник: ***Come** here!* / *I'll **come** to your party.*

## Go + прикметник: поширені вирази

*go wrong, go bad, go grey (сивіти), go bald (лисіти), go quiet, go missing, go viral, go crazy*: *Something has **gone wrong**.* / *The milk has **gone off**.*

## Been і gone у Present Perfect

***Where have you been?*** — Де ти був (тепер повернувся)? / ***Where has she gone?*** — Куди вона пішла (її немає)? Див. «Present Perfect: simple, continuous і різниця з Past Simple».

## Go for, go with, go on

- *I'll **go for** the fish.* — Візьму рибу (вибір).
- *Does this tie **go with** my shirt?* — Пасує до.
- *What's **going on**?* — Що відбувається?

## Типові помилки

- ✗ *go to home* → ✓ ***go home***
- ✗ *go to swimming* → ✓ ***go swimming***
- ✗ *She has been to London.* (якщо вона зараз там) → ✓ *She **has gone** to London.*
- ✗ *go by foot* → ✓ *go **on** foot*
- ✗ *Can I go to your party?* → ✓ *Can I **come** to your party?*
- ✗ *Something went bad with the computer.* → ✓ *Something went **wrong** with the computer.*
