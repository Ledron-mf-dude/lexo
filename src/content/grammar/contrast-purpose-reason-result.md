## Contrast (контраст)

| Слово | Що далі | Приклад |
| --- | --- | --- |
| **although / though / even though** | підмет + дієслово | **Although** it was raining, we went out. |
| **despite / in spite of** | іменник / -ing | **Despite** the rain, we went out. |
| **despite the fact that** | підмет + дієслово | **Despite the fact that** it rained… |
| **however / nevertheless** | окреме речення, кома | It was raining. **However,** we went out. |
| **but** | між частинами | It rained, **but** we went out. |
| **while / whereas** | протиставлення | Tom is tall, **whereas** his brother is short. |

Після `although` немає `but`: ~~Although it rained, but we went.~~ `Even though` — сильніше, ніж `although`.

## Purpose (мета)

| Схема | Приклад |
| --- | --- |
| **to + V** | I went to the shop **to buy** milk. |
| **in order to / so as to + V** | She works hard **in order to** succeed. |
| **so that + речення** (`can / could / will / would`) | I spoke slowly **so that** he **could** understand. |
| **for + іменник / -ing** | This tool is **for cutting** wood. |

Заперечення: *in order **not to** be late.*

## Reason (причина)

| Слово | Що далі | Приклад |
| --- | --- | --- |
| **because** | речення | He left **because** he was tired. |
| **since / as** | речення (відома причина) | **As** it was late, we left. |
| **because of / due to / owing to / on account of** | іменник / -ing | We stayed **because of** the weather. |

## Result (наслідок)

| Слово | Приклад |
| --- | --- |
| **so** | It was late, **so** we left. |
| **therefore** | He was ill; **therefore**, he stayed home. |
| **as a result / consequently** | **As a result,** prices rose. |
| **so / such … that** | It was **so** cold **that** we stayed home. |

Докладніше про `so … that`: «So, such». Слова-зв'язки для тексту: «Discourse markers».
