Складні прикметники складаються з кількох слів і пишуться **через дефіс** перед іменником.

## Число + іменник

Іменник у складі прикметника — **в однині**:

| Складний прикметник | Речення |
| --- | --- |
| a **two-day** trip | The trip lasts **two days**. |
| a **ten-year-old** boy | The boy is **ten years old**. |
| a **five-minute** walk | The walk takes **five minutes**. |
| a **three-course** meal | The meal has **three courses**. |

Не кажемо ~~a two-days trip~~.

## Інші моделі

| Модель | Приклад |
| --- | --- |
| **прислівник + participle** | **well-known** author, **badly-paid** job |
| **іменник + participle** | **time-consuming**, **home-made**, **hand-written** |
| **прикметник + -ed** | **blue-eyed**, **short-haired** |
| **прикметник + іменник** | **full-time**, **part-time**, **long-term**, **high-quality** |
| **self-** | **self-confident**, **self-employed** |
| **інші** | **old-fashioned**, **easy-going**, **hard-working**, **good-looking** |

## Позиція

- **Перед іменником** — з дефісом: *a **well-known** actor*.
- **Після дієслова** — часто без дефіса: *The actor is **well known**.*
- Числові — завжди однина перед іменником: *a **ten-minute** delay*.

## Приклади

- *She has a **full-time** job.* / *He works **part-time**.*
- *It was a **hard-working** team.*
- *I bought a **five-year-old** car.*

## Типові помилки

- ✗ *a two-days trip* → ✓ *a **two-day** trip* (іменник в однині)
- ✗ *a ten years old boy* → ✓ *a **ten-year-old** boy*
- ✗ *a five minutes walk* → ✓ *a **five-minute** walk*
- ✗ *She is a well known actor who is well-known.* → ✓ *a **well-known** actor* / *The actor is **well known**.*
