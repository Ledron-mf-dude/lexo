Доповнення до статті «Умовні речення».

## Слова замість if

| Слово | Значення | Приклад |
| --- | --- | --- |
| **unless** | якщо не (= if … not) | **Unless** you hurry, you'll be late. |
| **provided / providing (that)** | за умови, що | I'll go **provided that** it's free. |
| **as long as / so long as** | за умови, поки | You can stay **as long as** you're quiet. |
| **on condition that** | за умови (формально) | He agreed **on condition that** I pay. |
| **supposing / suppose (that)** | припустимо, що | **Supposing** you fail, what then? |
| **even if** | навіть якщо | I'll go **even if** it rains. |
| **in case** | на випадок | Take a coat **in case** it's cold. |
| **otherwise / or else** | інакше | Leave now, **otherwise** you'll miss it. |

- `Unless` не вживаємо з **питанням** і зазвичай з третім умовним.

## If it weren't for / But for

Означають «якби не»:

- ***If it weren't for** your help, I would fail.* = ***But for** your help, I would fail.*
- ***If it hadn't been for** the rain, we would have gone.* (минуле)

## If + were to / should

- ***If** I **were to** win, I'd buy a house.* — Якби мені (гіпотетично) довелося виграти…
- ***If** you **should** need help, call me.* — Якщо раптом знадобиться допомога…

## Інверсія (формальний стиль)

Без `if`: допоміжне дієслово виходить **на початок**.

| Звичайна форма | З інверсією |
| --- | --- |
| If I **had known**, I'd have told you. | **Had I known**, I'd have told you. |
| If you **should** need help, call me. | **Should you** need help, call me. |
| If I **were** you, I'd go. | **Were I** you, I'd go. |
| If it **weren't** for you… | **Were it not for** you… |

Інверсія в запереченні: **Had I not** known…, **Were I not** busy… Див. також «Inversion».

## But for, without, otherwise

- ***Without** your help, I would have failed.* = *If you hadn't helped me…*
- *I took a taxi; **otherwise** I'd have been late.*
- ***But for** the rain, we would have won.* (книжно)

## Imagine, assuming, what if

- ***Imagine** you won the lottery — what would you do?*
- ***Assuming** the weather is fine, we'll go.* — якщо (припускаючи)
- ***What if** we miss the train?* — а що, як…

## Змішані умовні з модальними

*If I **had studied** medicine, I **could be** a doctor now.* / *If she **weren't** so shy, she **might have** asked him.* Див. «Умовні речення (conditionals): zero, first, second, third, mixed».

## Як вибрати

1. «Якщо не…» — ***unless*** (= *if … not*).
2. «За умови, що, аби тільки» — ***as long as / provided (that) / providing***.
3. «На випадок, якщо» — ***in case*** (запобіжно).
4. «Навіть якщо» — ***even if***.
5. «Інакше» — ***otherwise*** (окрема частина речення).
6. «Якби не…» — *If it weren't for / Without / But for* (зараз), *If it hadn't been for* (у минулому).
7. Формально, без *if* — інверсія: *Had I known…*, *Should you need…*, *Were I you…*

## Пастки перекладу

- *unless* вже містить заперечення: *Unless you hurry* (а не *Unless you don't hurry*).
- «Візьми гроші на випадок, якщо знадобиться таксі» — *in case you need a taxi*: після *in case* — теперішній час, не *will*.
- «Якби не твоя допомога» — *Without your help* або *If it weren't for your help*.
- Інверсія звучить формально: у розмові частіше звичайне *If I had known…*

## Типові помилки

- ✗ *Unless you don't hurry, you'll be late.* → ✓ ***Unless** you hurry…* (unless вже містить заперечення)
- ✗ *In case it will rain, take an umbrella.* → ✓ *…in case it **rains**.*
- ✗ *If I would have known…* → ✓ ***Had I known…*** / *If I **had** known…*
- ✗ *Should you will need help…* → ✓ ***Should you need** help…*
- ✗ *Without your help, I would fail yesterday.* → ✓ *Without your help, I **would have failed** yesterday.*
- ✗ *Assuming the weather will be fine, we'll go.* → ✓ *Assuming the weather **is** fine, we'll go.*
