Окличне речення висловлює **емоцію**: захват, здивування, роздратування. В англійській для цього є кілька готових схем, і вибір між ними залежить від того, **що йде після** оклику: іменник чи прикметник.

> ***What a** beautiful day!* — Який чудовий день! &nbsp; ***How** beautiful!* — Як гарно!

## What + іменник

| Іменник | Схема | Приклад |
| --- | --- | --- |
| Лічильний в однині | **What a / an** (+ прикметник) + іменник | **What a** view! / **What an** amazing idea! |
| Лічильний у множині | **What** (+ прикметник) + іменник | **What** lovely flowers! |
| Нелічильний | **What** (+ прикметник) + іменник | **What** awful weather! / **What** good news! |

Артикль `a / an` з'являється **лише** з лічильним іменником в однині, як і в звичайному реченні: *a view → What a view!*, але *weather → What weather!*

> Нелічильні, які українською здаються «поштучними», і тут без артикля: ***What** nice furniture!*, ***What** useful advice!*, ***What** terrible luck!* Див. «Лічильні й нелічильні іменники».

## How + прикметник або прислівник

| Схема | Приклад |
| --- | --- |
| **How** + прикметник | **How** strange! / **How** kind of you! |
| **How** + прикметник + підмет + дієслово | **How** tall you've grown! |
| **How** + прислівник + підмет + дієслово | **How** fast she runs! / **How** well you speak English! |
| **How** + підмет + дієслово (про саму дію) | **How** I love this song! (емоційно, трохи книжно) |

Після `how` ніколи не ставимо іменник: не *How a nice day!*, а ***What a** nice day!*

## Порядок слів: без інверсії

Окличне речення — **не питання**, тож підмет стоїть **перед** дієсловом:

| Окличне | Питання |
| --- | --- |
| **What a big house they have!** | **What** house **do they** have? |
| **How cold it is!** | **How** cold **is it**? |

## Повне і коротке

Найчастіше говорять коротко, без підмета й дієслова:

- *What a mess!* — Який безлад!
- *What a pity!* / *What a shame!* — Шкода!
- *What a relief!* — Яке полегшення!
- *How rude!* — Як грубо!
- *How interesting!* — Як цікаво!

Повна форма підкреслює деталь: *What a mess **you've made**!* / *How rude **he was**!*

## So і such в окличних реченнях

Ті самі слова, що в статті «So, such, such a, so much, so many», теж передають емоцію:

| Схема | Приклад |
| --- | --- |
| **so** + прикметник / прислівник | It's **so** cold! / She sings **so** beautifully! |
| **such a / an** + (прикметник) + іменник в однині | It was **such a** good film! |
| **such** + (прикметник) + множина / нелічильне | They're **such** nice people! / It's **such** bad weather! |

*How cold it is!* ≈ *It's so cold!* — значення однакове, друге звучить розмовніше.

## Інші способи

- **Заперечне питання із спадною інтонацією** — це теж оклик: ***Isn't it** lovely!* / ***Wasn't that** fun!* (не справжнє питання, тому часто зі знаком оклику).
- **Підсилювачі:** *That's **really** amazing!* / *It was **absolutely** fantastic!*
- **Вигуки:** *Wow!*, *Oh no!*, *Ouch!* (біль), *Oops!* (помилка), *Yuck!* (гидота), *Phew!* (полегшення).

## Як вибрати

1. Далі іменник? — ***What***: з лічильним в однині — *What a…!*, з множиною чи нелічильним — *What…!* без *a*.
2. Далі лише прикметник чи прислівник? — ***How***: *How beautiful!*, *How fast you run!*
3. У звичайному реченні: *so* + прикметник; *such (a)* + іменник.
4. Після *How / What* — прямий порядок слів: *How tall you've grown!*

## Пастки перекладу

- «Яка погода!» — *What weather!* (нелічильне, без *a*), а не *What a weather*.
- «Який гарний день!» — *What a beautiful day!*: тут *a* обов'язковий.
- «Як вона гарно співає!» — *How beautifully she sings!*, без інверсії.
- «Так холодно!» — *It's so cold!*, а не *such cold*.

## Типові помилки

- ✗ *What beautiful day!* → ✓ *What **a** beautiful day!*
- ✗ *What a terrible weather!* → ✓ ***What** terrible weather!* (weather — нелічильне)
- ✗ *How a nice house!* → ✓ ***What a** nice house!* (з іменником — what)
- ✗ *How beautiful is she!* → ✓ *How beautiful **she is**!* (без інверсії)
- ✗ *It's such cold today!* → ✓ *It's **so** cold today!* (перед прикметником без іменника — so)
- ✗ *What a good news!* → ✓ ***What** good news!* (news — нелічильне)
