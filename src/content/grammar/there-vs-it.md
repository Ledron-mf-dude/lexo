Англійське речення **потребує підмета**. Коли реального підмета немає, вживають **there** або **it**.

## There: щось існує

`There` вводить **нову інформацію**, що щось є:

- ***There is** a cat in the garden.*
- ***There are** three problems.*

## It: конкретна річ чи «порожній» підмет

| Використання | Приклад |
| --- | --- |
| **Раніше згадана річ** | I bought a car. **It** is red. |
| **Погода** | **It** is raining. **It's** cold. |
| **Час і дата** | **It's** ten o'clock. **It's** Monday. |
| **Відстань** | **It's** five miles to town. |
| **Підготовчий підмет** (інфінітив / that) | **It** is nice to see you. |
| **Тривалість** | **It takes** two hours to get there. |

## Підготовчий підмет it

Довгий підмет переносимо в кінець, а на початку ставимо `it`:

| Довго | Природніше |
| --- | --- |
| To learn English is difficult. | **It is** difficult **to learn** English. |
| That she left surprised me. | **It surprised** me **that** she left. |
| Meeting you was a pleasure. | **It was** a pleasure **meeting** you. |

Типові схеми: **it is + прикметник + to-inf / that**; **it takes / costs / seems + …**

## There чи it?

| | There | It |
| --- | --- | --- |
| **Функція** | нова інформація | відома річ / порожній підмет |
| **Приклад** | **There is** a dog outside. | **It** is big. |
| **З прикметником** | **There is** nothing **special**. | **It's** special. |
| **Можливо** | There **is no need** to hurry. | **It is not necessary** to hurry. |

## This чи it?

- *This is my phone. **It** is new.* Див. «This, that, these, those».

## Типові помилки

- ✗ *Is raining.* → ✓ ***It** is raining.* (підмет обов'язковий)
- ✗ *There is difficult to learn English.* → ✓ ***It** is difficult to learn English.*
- ✗ *It is a problem with the printer.* (нова інформація) → ✓ ***There is** a problem…*
- ✗ *Takes two hours.* → ✓ ***It takes** two hours.*
