**Compound noun** — іменник із двох і більше слів, який означає одне поняття: *bus stop, toothpaste, mother-in-law*.

## Типові моделі

| Модель | Приклад |
| --- | --- |
| **іменник + іменник** | **bus** stop, **tea**spoon, **phone** number, **sun**flower |
| **прикметник + іменник** | **black**board, **full** moon, **soft**ware |
| **-ing + іменник** | **swimming** pool, **washing** machine, **living** room |
| **іменник + -ing** | **weight**lifting, **sight**seeing |
| **дієслово + прийменник** | **check-in**, **break-up**, **take-off** |
| **іменник + прийменник + іменник** | **mother-in-law**, **editor-in-chief** |

## Написання

Можливі **три** варіанти: **разом** (*toothpaste*), **через дефіс** (*mother-in-law*), **окремо** (*bus stop*). Точного правила немає: перевіряйте в словнику.

## Наголос

Зазвичай наголос на **першому** слові: **BLACKboard** (дошка), а не *black BOARD* (чорна дошка як прикметник + іменник).

## Множина

Змінюється **головний** (останній) елемент:

| Однина | Множина |
| --- | --- |
| bus stop | bus **stops** |
| toothbrush | toothbrush**es** |
| swimming pool | swimming pool**s** |

Виняток: коли головний іменник **не в кінці**:

| Однина | Множина |
| --- | --- |
| mother-in-law | mother**s**-in-law |
| passer-by | passer**s**-by |

Кілька перших елементів мають форму множини й так і залишаються: *a **sports** car → sports cars*, *a **savings** account*, *a **clothes** shop*. Зазвичай же перший іменник стоїть в однині: *a **shoe** shop* (не *shoes shop*), *a **ten-dollar** bill*.

## Присвійне

's додаємо в **кінці**: *my **mother-in-law's** car*. Див. «Присвійна форма».

## Іменник + іменник чи 's / of?

| Тип | Приклад |
| --- | --- |
| **вид, призначення** — compound noun | a **coffee cup** (чашка для кави), a **bus driver** |
| **належність людині чи тварині** — 's | **the driver's** seat, **a dog's** tail |
| **частина цілого, вміст** — of | a cup **of** coffee (чашка з кавою), the top **of** the box |

## Множина в перших словах

Перший іменник зазвичай в **однині**, навіть коли значення множинне: *a **toothbrush*** (не *teethbrush*), *a **shoe** shop*, *a **car** park*. Винятки, де множина лишається: *sports car, clothes shop, savings account, sales manager, arms race*.

## Довгі ланцюжки

У новинах і технічних текстах трапляються ланцюжки з трьох-чотирьох іменників: *a **city centre parking** problem*. Читайте їх **з кінця**: проблема → з паркуванням → у центрі міста.

## Типові помилки

- ✗ *buses stop* → ✓ *bus **stops*** (множину отримує головне, останнє слово)
- ✗ *mother-in-laws* → ✓ *mother**s**-in-law*
- ✗ *a shoes shop* → ✓ *a **shoe** shop*
- ✗ *a black board* (чорна дошка) ≠ *a **blackboard*** (шкільна дошка) — різне значення
- ✗ *I'd like a coffee's cup.* → ✓ *I'd like a **coffee cup**.* / *I'd like a cup of coffee.*
- ✗ *We need a teethbrush.* → ✓ *We need a **toothbrush**.*
