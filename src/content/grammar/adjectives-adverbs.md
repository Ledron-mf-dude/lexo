## Різниця

| | Що описує | Приклад |
| --- | --- | --- |
| **Adjective** | іменник | a **slow** car, an **interesting** book |
| **Adverb** | дієслово, прикметник, інший прислівник | She drives **slowly**. / **very** interesting |

## Утворення прислівників

| Правило | Приклад |
| --- | --- |
| adjective + **-ly** | slow → slow**ly**, quick → quick**ly** |
| **-y** → **-ily** | happy → happ**ily**, easy → eas**ily** |
| **-le** → **-ly** | simple → simp**ly**, gentle → gent**ly** |
| **-ic** → **-ically** | basic → basic**ally** |

## Неправильні прислівники

| Прикметник | Прислівник |
| --- | --- |
| **good** | **well** |
| **fast** | **fast** |
| **hard** | **hard** (наполегливо) |
| **late** | **late** (пізно) |
| **early** | **early** |

- *She's a **good** singer.* → *She sings **well**.*
- *He works **hard**.* (не *hardly*)

## Слова з різним значенням

| Слово | Значення |
| --- | --- |
| **hard** | наполегливо → *work hard* |
| **hardly** | ледве, майже не → *I **hardly** know him.* |
| **late** | пізно → *arrive late* |
| **lately** | останнім часом → *I've been busy lately.* |
| **near** | близько → *live near* |
| **nearly** | майже → *nearly finished* |

## Дієслова-«зв'язки» + прикметник

Після **be, seem, look, feel, sound, taste, smell, become, get** ставимо **прикметник**, а не прислівник:

- *She looks **happy**.* / *It tastes **good**.* / *I feel **tired**.*

Порівняйте: *She looked **angrily** at me* (діє) — *She looked **angry*** (стан). Див. «Verbs of the senses».

## Позиція прислівників способу

- Після дієслова або додатка: *She speaks **slowly**.* / *He opened the door **quietly**.*
- Між `to be` і прикметником: *very **happy***.
