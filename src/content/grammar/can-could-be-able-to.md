## Can

| Значення | Приклад |
| --- | --- |
| Вміння | I **can** swim. |
| Можливість | We **can** meet at 5. |
| Дозвіл | You **can** park here. |
| Прохання (неформальне) | **Can** you help me? |
| Загальна можливість («буває») | It **can** be very cold here in winter. |
| Пропозиція допомоги | **Can** I help you? |

Заперечення: **can't / cannot** (пишеться разом). Після `can` — інфінітив **без to**. Немає форми `-s`: *She **can** sing.* Питання — без `do`: ***Can** you swim?* — *Yes, I **can**.* / *No, I **can't**.*

## Could

| Значення | Приклад |
| --- | --- |
| Вміння **в минулому** (загалом) | When I was five, I **could** read. |
| Ввічливе прохання | **Could** you open the window? |
| Припущення / можливість | It **could** rain later. |

## Дозвіл: can, could, may, be allowed to

| Що | Приклад |
| --- | --- |
| Попросити дозволу (від простого до ввічливого) | **Can** I sit here? → **Could** I sit here? → **May** I sit here? |
| Дати дозвіл | Yes, of course you **can**. (не *you could*) |
| Відмовити | Sorry, you **can't**. |
| Дозвіл у минулому (загалом) | When I was a child, I **could** stay up late on Fridays. |
| Дозвіл у минулому (конкретний випадок) | Yesterday we **were allowed to** leave early. |
| Майбутнє | You **will be allowed to** vote next year. |

`Could I…?` — прохання про **теперішнє**, а не минуле. Відповідаємо `can`: *Could I open the window? — Yes, you **can**.*

## Прохання: від простого до ввічливого

| Форма | Відтінок |
| --- | --- |
| **Can** you pass the salt? | звичайно, між своїми |
| **Could** you pass the salt? | ввічливіше |
| **Would** you pass the salt, please? | ввічливо, трохи офіційно |
| **Would you mind passing** the salt? | дуже ввічливо (після mind — -ing) |
| **Do you think you could** help me? | обережно, м'яко |

## Be able to

Використовується там, де `can` немає форми: в **усіх часах**, з інфінітивом, після інших дієслів.

| Час | Приклад |
| --- | --- |
| Present | I **am able to** drive. |
| Past | I **was able to** finish on time. |
| Present Perfect | I **have been able to** relax lately. |
| Future | I **will be able to** come tomorrow. |
| Інфінітив / gerund | I'd love **to be able to** sing. / **Being able to** swim is useful. |

## Could чи was able to?

| Ситуація | Форма |
| --- | --- |
| Загальне вміння в минулому | I **could** swim at six. |
| **Одна конкретна** вдала дія в минулому | Yesterday I **was able to** / **managed to** finish. (не *could*) |
| Заперечення (будь-яка ситуація) | I **couldn't** / **wasn't able to** open it. |

> З дієсловами сприйняття й мислення (*see, hear, understand, remember*) частіше `could`: *I **could see** him.*

`Managed to` підкреслює, що вдалося **з зусиллям**: *The door was stuck, but I **managed to** open it.*

## Can't і could: припущення

`Can't` — упевненість, що щось **неможливо**: *That **can't** be true!* `Could` — що щось **можливо**: *She **could** be at work.* Докладніше: «Модальні дієслова: припущення (might, may, should, must, can't)».

## Типові помилки

- ✗ *I will can help you.* → ✓ *I **will be able to** help you.*
- ✗ *She cans swim.* → ✓ *She **can** swim.*
- ✗ *I can to drive.* → ✓ *I can **drive**.*
- ✗ *Yesterday I could finish the report.* (вдала одноразова дія) → ✓ *…I **was able to / managed to** finish…*
- ✗ *Do you can swim?* → ✓ ***Can** you swim?*
- ✗ *"Could I sit here?" — "Yes, you could."* → ✓ *"Could I sit here?" — "Yes, you **can**."*
- ✗ *I'd like to can speak French.* → ✓ *I'd like **to be able to** speak French.*
- ✗ *Would you mind to open the window?* → ✓ *Would you mind **opening** the window?*
