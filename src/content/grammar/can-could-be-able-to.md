## Can

| Значення | Приклад |
| --- | --- |
| Вміння | I **can** swim. |
| Можливість | We **can** meet at 5. |
| Дозвіл | You **can** park here. |
| Прохання (неформальне) | **Can** you help me? |

Заперечення: **can't / cannot**. Після `can` — інфінітив **без to**. Немає форми `-s`: *She **can** sing.*

## Could

| Значення | Приклад |
| --- | --- |
| Вміння **в минулому** (загалом) | When I was five, I **could** read. |
| Ввічливе прохання | **Could** you open the window? |
| Припущення / можливість | It **could** rain later. |

## Be able to

Використовується там, де `can` немає форми: в **усіх часах**, з інфінітивом, після інших дієслів.

| Час | Приклад |
| --- | --- |
| Present | I **am able to** drive. |
| Past | I **was able to** finish on time. |
| Present Perfect | I **have been able to** relax lately. |
| Future | I **will be able to** come tomorrow. |
| Інфінітив / gerund | I'd love **to be able to** sing. / **Being able to** swim is useful. |

## Could чи was able to?

| Ситуація | Форма |
| --- | --- |
| Загальне вміння в минулому | I **could** swim at six. |
| **Одна конкретна** вдала дія в минулому | Yesterday I **was able to** / **managed to** finish. (не *could*) |
| Заперечення (будь-яка ситуація) | I **couldn't** / **wasn't able to** open it. |

> З дієсловами сприйняття й мислення (*see, hear, understand, remember*) частіше `could`: *I **could see** him.*

## Типові помилки

- ✗ *I will can help you.* → ✓ *I **will be able to** help you.*
- ✗ *She cans swim.* → ✓ *She **can** swim.*
- ✗ *I can to drive.* → ✓ *I can **drive**.*
- ✗ *Yesterday I could finish the report.* (вдала одноразова дія) → ✓ *…I **was able to / managed to** finish…*
