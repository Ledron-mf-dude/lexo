Означальне підрядне речення уточнює іменник: *«людина, **яка**…», «місце, **де**…»*.

## Відносні слова

| Слово | Для чого | Приклад |
| --- | --- | --- |
| **who** | людей | The man **who** called is my boss. |
| **which** | речей, тварин | The book **which** I read was great. |
| **that** | людей і речей (лише в defining) | The book **that** I read was great. |
| **where** | місць | The café **where** we met has closed. |
| **whose** | належності | The girl **whose** bag was stolen is here. |
| **when** | часу | I remember the day **when** we met. |

## Defining і non-defining

| | Defining (обмежувальне) | Non-defining (додаткове) |
| --- | --- | --- |
| Роль | Потрібне, щоб зрозуміти, **про кого/що** мова | Додаткова інформація |
| Коми | **Без ком** | **У комах** |
| `that` | можна | **не можна** |
| Приклад | The teacher **who** helped me is kind. | My teacher, **who** is very kind, helped me. |

## Опускання відносного слова

Якщо слово є **додатком** (не підметом) у defining clause, його можна опустити:

- *The film **(that)** we watched was long.*
- *The man **(who)** I met yesterday is a doctor.*

Якщо воно **підмет** — опускати не можна: *The man **who** lives next door…*

## Which про всю ситуацію

- *He passed the exam, **which** surprised everyone.* — Він склав іспит, і це всіх здивувало.

## Типові помилки

- ✗ *The man which called is my boss.* → ✓ *The man **who / that** called…*
- ✗ *My brother, that lives in Kyiv, is a doctor.* → ✓ *My brother, **who** lives in Kyiv…* (у комах — без that)
- ✗ *The book what I read was great.* → ✓ *The book **that / which** I read…*
- ✗ *The man lives next door is kind.* → ✓ *The man **who** lives next door…* (підмет не опускаємо)
- ✗ *The café where we met there has closed.* → ✓ *The café where we met has closed.*
