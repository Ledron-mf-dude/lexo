## Question tags (розділові запитання)

Коротке питання в кінці речення: «…, правда?». Використовуємо, щоб підтвердити сказане або м'яко перепитати.

**Правило: ствердження → заперечний тег, заперечення → ствердний.** Допоміжне дієслово беремо те саме, що в реченні.

| Речення | Тег |
| --- | --- |
| She **is** late, | **isn't she?** |
| You **don't** like it, | **do you?** |
| They **have** left, | **haven't they?** |
| He **can** swim, | **can't he?** |
| You **live** here, | **don't you?** |
| She **went** home, | **didn't she?** |
| You **will** come, | **won't you?** |

## Винятки

| Речення | Тег |
| --- | --- |
| **I am** right, | **aren't I?** |
| **Let's** go, | **shall we?** |
| **Open** the window, (наказ) | **will you?** |
| There **is** a problem, | **isn't there?** |
| Nobody called, | **did they?** |

## Інтонація

- **Спадна** (голос падає): ми впевнені, просто підтверджуємо. *It's cold, isn't it?* ↘
- **Висхідна** (голос іде вгору): справжнє питання. *You're coming, aren't you?* ↗

## So am I / Neither do I

Згода з чужими словами:

| Сказали | Ви згодні |
| --- | --- |
| I **like** pizza. | **So do I.** / Me too. |
| I'**m** tired. | **So am I.** |
| I **can** swim. | **So can I.** |
| I **don't** like fish. | **Neither do I.** / Me neither. |
| I **haven't** eaten. | **Neither have I.** |

Після `so` і `neither` — **допоміжне дієслово + підмет**. З `neither` дієслово в ствердній формі: не *Neither don't I*.
