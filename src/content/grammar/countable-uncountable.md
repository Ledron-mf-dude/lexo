Від того, чи можна іменник порахувати поштучно, залежать артикль, форма дієслова і слова кількості. Українське «відчуття» тут часто підводить: *порада* лічильна, а **advice** — ні.

## Різниця

| Лічильні (countable) | Нелічильні (uncountable) |
| --- | --- |
| Можна порахувати: *one book, two books* | Не рахується поштучно: *water, money* |
| Мають множину | **Немає** множини |
| **a / an** в однині: *a car* | Без **a / an** |
| **many, few, a few**: *many cars* | **much, little, a little**: *much water* |
| Дієслово в однині чи множині | Дієслово лише в **однині** |

## Типові нелічильні

| Група | Слова |
| --- | --- |
| Їжа й напої | water, milk, bread, rice, sugar, coffee, cheese, butter, meat, pasta, fruit (загалом) |
| Матеріали | wood, paper, glass, gold, plastic, cotton |
| Абстрактні | information, advice, help, news, knowledge, homework, work, progress, luck, fun, research, evidence |
| Збірні | money, furniture, luggage, baggage, traffic, equipment, rubbish, accommodation |
| Явища й речовини | weather, rain, snow, air, electricity, music |
| Предмети вивчення | maths, physics, economics (з -s, але однина) |

Дієслово — в **однині**: *The **information is** useful.* / *The **news is** bad.* / *My **luggage is** heavy.*

## Як порахувати нелічильне

Вживаємо **одиницю виміру** або «порцію»:

| Слово | Приклади |
| --- | --- |
| **a piece of** | a piece of advice / information / furniture / news / cake, two pieces of luggage |
| **a glass / cup / bottle of** | a glass of water, a cup of tea, a bottle of milk |
| **a loaf / slice of** | a loaf of bread, a slice of cheese |
| **a bar / packet / tin (can) of** | a bar of chocolate, a packet of rice, a tin of tuna |
| **a kilo / litre of** | a kilo of sugar, a litre of oil |
| **an item / a bit of** | an item of clothing, a bit of luck |

## Some, any, much, a lot of

| | Ствердження | Заперечення | Питання |
| --- | --- | --- | --- |
| **Лічильні (мн.)** | some books, a lot of books | any books, many books | any books? how many? |
| **Нелічильні** | some water, a lot of water | any water, much water | any water? how much? |

`Some` у питаннях — коли пропонуємо чи просимо: *Would you like **some** tea?* Більше про кількість: «Quantifiers».

## Пастки

Слова, які в українській лічильні, а в англійській — **ні**:

- *advice, information, furniture, luggage, news, progress, homework, knowledge, research, equipment, accommodation*
- Неправильно: ~~an advice, informations, furnitures~~. Правильно: **a piece of advice**, **some information**, **some furniture**.

Часто можна замінити слово лічильним синонімом: *a suggestion* (≈ advice), *a fact* (≈ information), *a job* (≈ work), *a suitcase* (≈ luggage).

## Одне слово — два значення

| Нелічильне (загалом, речовина) | Лічильне (окремий предмет, випадок) |
| --- | --- |
| **glass** — скло | **a glass** — склянка; **glasses** — окуляри |
| **paper** — папір | **a paper** — газета; наукова стаття |
| **time** — час | **a time** — раз: *I've been there three **times**.* / *We had **a great time**.* |
| **experience** — досвід (знання) | **an experience** — пригода, випадок: *It was **an amazing experience**.* |
| **room** — місце, простір: *Is there **room** for me?* | **a room** — кімната |
| **hair** — волосся (усе): *She has long **hair**.* | **a hair** — одна волосина: *There's **a hair** in my soup.* |
| **chicken** — курятина | **a chicken** — курка (птах) |
| **coffee** — кава (напій загалом) | **a coffee** — чашка кави: *Two **coffees**, please.* |
| **business** — бізнес, справи | **a business** — компанія |
| **work** — робота (праця) | **a work** — твір: *a work of art* |

## Типові помилки

- ✗ *an advice* → ✓ ***a piece of** advice* / ***some** advice*
- ✗ *informations, furnitures, luggages* → ✓ *information, furniture, luggage* (без -s)
- ✗ *The news are bad.* → ✓ *The news **is** bad.*
- ✗ *many money* → ✓ ***much / a lot of** money*
- ✗ *How many water?* → ✓ *How **much** water?*
- ✗ *She has long hairs.* → ✓ *She has long **hair**.*
- ✗ *I have a lot of homeworks.* → ✓ *I have a lot of **homework**.*
- ✗ *We had a terrible weather.* → ✓ *We had **terrible weather**.*
- ✗ *I need an information about the course.* → ✓ *I need **some information** about the course.*
- ✗ *He has a big experience in sales.* → ✓ *He has **a lot of experience** in sales.*

Див. «Quantifiers» і «Артиклі: a / an / the / без артикля».
