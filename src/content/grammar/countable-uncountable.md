## Різниця

| Лічильні (countable) | Нелічильні (uncountable) |
| --- | --- |
| Можна порахувати: *one book, two books* | Не рахується поштучно: *water, money* |
| Мають множину | **Немає** множини |
| **a / an**: *a car* | Без **a / an** |
| **many, few**: *many cars* | **much, little**: *much water* |

## Типові нелічильні

| Група | Слова |
| --- | --- |
| Їжа й напої | water, milk, bread, rice, sugar, coffee, cheese |
| Матеріали | wood, paper, glass, gold |
| Абстрактні | information, advice, help, news, knowledge, homework, work, progress, luck |
| Збірні | money, furniture, luggage, traffic, weather, equipment |

Дієслово — в **однині**: *The **information is** useful.* / *The **news is** bad.*

## Як порахувати нелічильне

Вживаємо **одиницю виміру**: *a **piece of** advice, a **glass of** water, a **loaf of** bread, a **bottle of** milk, two **pieces of** luggage*.

## Some, any

| | Ствердження | Заперечення | Питання |
| --- | --- | --- | --- |
| **Лічильні (мн.)** | some books | any books | any books? |
| **Нелічильні** | some water | any water | any water? |

`Some` у питаннях — коли пропонуємо: *Would you like **some** tea?*

## Пастки

Слова, які в українській лічильні, а в англійській — **ні**:

- *advice, information, furniture, luggage, news, progress, homework, knowledge*
- Неправильно: ~~an advice, informations, furnitures~~. Правильно: **a piece of advice**, **some information**, **some furniture**.

Деякі слова мають обидва значення: *a **glass** (склянка) — **glass** (скло)*, *a **paper** (газета) — **paper** (папір)*.

## Типові помилки

- ✗ *an advice* → ✓ ***a piece of** advice* / ***some** advice*
- ✗ *informations, furnitures, luggages* → ✓ *information, furniture, luggage* (без -s)
- ✗ *The news are bad.* → ✓ *The news **is** bad.*
- ✗ *many money* → ✓ ***much / a lot of** money*
- ✗ *How many water?* → ✓ *How **much** water?*

Див. «Quantifiers».
