Багато англійських дієслів вимагають **певного прийменника**. Їх треба запам'ятовувати разом.

## Найпоширеніші

| Прийменник | Дієслова |
| --- | --- |
| **on** | depend **on**, rely **on**, insist **on**, spend money **on**, concentrate **on** |
| **to** | listen **to**, talk **to**, belong **to**, happen **to**, reply **to**, look forward **to** |
| **for** | wait **for**, ask **for**, look **for**, pay **for**, apologise **for**, search **for**, thank sb **for** |
| **at** | look **at**, laugh **at**, arrive **at** (місце), aim **at**, stare **at** |
| **about** | think **about**, worry **about**, talk **about**, care **about**, dream **about** |
| **of** | think **of**, dream **of**, consist **of**, approve **of**, remind sb **of** |
| **in** | believe **in**, succeed **in**, arrive **in** (місто), result **in** |
| **with** | agree **with**, deal **with**, argue **with**, cope **with** |
| **from** | suffer **from**, differ **from**, protect **from**, escape **from** |

## Приклади

- *It **depends on** the weather.*
- *Please **listen to** me.* / *I'm **waiting for** the bus.*
- *She **apologised for** being late.*
- *I **believe in** you.* / *He **succeeded in** passing the exam.*
- *We **agree with** you.* / *She **suffers from** headaches.*

## Різні прийменники — різні значення

| Дієслово | Значення |
| --- | --- |
| **look at** | дивитися на |
| **look for** | шукати |
| **look after** | доглядати |
| **think about** | думати про (процес) |
| **think of** | вважати, мати думку |
| **talk to** | розмовляти з (особою) |
| **talk about** | розмовляти про (тему) |

- *What do you **think of** the film?* — яка ваша думка.
- *I'm **thinking about** moving.* — розмірковую.

## Без прийменника (відмінність від української)

Англійські дієслова, що в українській мають прийменник, але тут — **без**:

- **discuss** sth (не *discuss about*): *We **discussed** the problem.*
- **enter** (не *enter into*): *She **entered** the room.*
- **marry** sb: *He **married** Anna.*
- **reach / attend / answer** sth: *We **reached** the top.* / *I **attended** the meeting.*
