**Номіналізація** — це коли дію чи ознаку передають **іменником**, а не дієсловом чи прикметником. Текст стає щільнішим і формальнішим: так пишуть звіти, статті, есе.

- *The company **decided** to expand.* → *The company's **decision** to expand…*
- *Prices **rose** sharply.* → *The sharp **rise** in prices…*
- *Because the train **arrived** late…* → *Because of the late **arrival** of the train…*

## Як утворюються іменники

| Суфікс | Приклади |
| --- | --- |
| -tion / -sion | decide → decision, explain → explanation, reduce → reduction |
| -ment | develop → development, agree → agreement, improve → improvement |
| -ance / -ence | perform → performance, prefer → preference, exist → existence |
| -al | arrive → arrival, refuse → refusal, approve → approval |
| -ure | fail → failure, close → closure, press → pressure |
| -ity / -ness | possible → possibility, able → ability, aware → awareness |
| -th | grow → growth, strong → strength, long → length |
| та сама форма | increase, rise, fall, change, decline, demand, use, delay |

## Що змінюється в реченні

- **Підмет** дієслова стає присвійною формою або *of*-фразою: *The government **reacted** quickly.* → *The government's quick **reaction** / the quick **reaction of** the government*.
- **Прислівник** стає **прикметником**: *sharply* → *a **sharp** rise*; *quickly* → *a **quick** reaction*.
- **Додаток** приєднується прийменником: *They **developed** new drugs.* → *the **development of** new drugs*.
- Причина, час, умова — прийменником замість сполучника: *because of, due to, after, on, despite, in the event of*: ***After** the **arrival** of the guests…*

## Прийменники після іменників

| Іменник | Прийменник | Приклад |
| --- | --- | --- |
| increase, rise, fall, decline, reduction, change | **in** | *a rise **in** unemployment* |
| demand, need, reason, responsibility | **for** | *the demand **for** housing* |
| effect, impact, influence | **on** | *the impact **on** the environment* |
| solution, answer, approach, access | **to** | *a solution **to** the problem* |
| discussion, information, concern | **about** | *concern **about** costs* |

## Дієслова, що працюють з іменниками

Номіналізована дія часто потребує «легкого» дієслова: ***make** a decision, **carry out** research, **take** action, **give** an explanation, **reach** an agreement, **come to** a conclusion, **have** an impact on, **pay** attention to*.

## Коли не варто

У розмові та простих текстах ланцюжки іменників звучать важко: ~~*The implementation of the improvement of the system…*~~ Краще *We improved the system.* Номіналізуйте там, де потрібен формальний стиль чи щільність, але не всі дієслова поспіль.

## Як вибрати

1. Формальний текст, треба стисло — дія іменником: *the decision, the growth, the arrival*.
2. Прислівник при дієслові стає прикметником при іменнику.
3. Хто виконує дію — присвійна форма або *of*; над чим — *of*.
4. Зміна кількості — *in*; потреба — *for*; вплив — *on*; розв'язання — *to*.
5. Іменнику потрібне дієслово — беріть сталу пару: *make a decision, carry out research*.

## Пастки перекладу

- Українська канцелярська мова теж любить іменники («здійснення контролю»), але англійські пари інші: «провести дослідження» — *carry out / do research*, не *make research*.
- «Зростання цін» — *a rise **in** prices*, не *a rise of prices*.
- «Через запізнення поїзда» — *because of **the** late arrival of the train*.

## Типові помилки

- ✗ *There has been a big increase of food prices this year.* → ✓ *There has been a big increase **in** food prices this year.*
- ✗ *We need to make a research before we decide.* → ✓ *We need to **do research** before we decide.* / *We need to **carry out research** before we decide.*
- ✗ *The arrive of the new manager changed everything.* → ✓ *The **arrival** of the new manager changed everything.*
- ✗ *There was a sharply rise in unemployment last year.* → ✓ *There was a **sharp** rise in unemployment last year.*
- ✗ *Due to prices rose, sales fell.* → ✓ *Due to **the rise in** prices, sales fell.*
- ✗ *The government's decide to raise taxes was unpopular.* → ✓ *The government's **decision** to raise taxes was unpopular.*
