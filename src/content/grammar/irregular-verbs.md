## Утворення Past Simple

| | Схема | Приклад |
| --- | --- | --- |
| Ствердження | V2 (**-ed** або 2-га форма) | She **worked** / **went** home. |
| Заперечення | did **not** (didn't) + V | She **didn't work**. |
| Питання | **Did** + підмет + V? | **Did** she **work**? |
| Коротка відповідь | Yes, she **did**. / No, she **didn't**. | |

Після `did` дієслово в **початковій** формі: *Did you **go**?* (не *Did you went*).

## To be: was / were

| Займенник | Форма |
| --- | --- |
| I / he / she / it | **was** |
| you / we / they | **were** |

Питання й заперечення без `did`: ***Was** he here? — He **wasn't** here.*

## Правильні дієслова: правопис -ed

| Правило | Приклад |
| --- | --- |
| Додаємо **-ed** | work → work**ed** |
| Закінчується на **-e** → **-d** | love → love**d** |
| Приголосний + **y** → **-ied** | study → stud**ied** |
| Голосний + y → **-ed** | play → play**ed** |
| Односкладове з CVC → подвоюємо | stop → stop**ped**, plan → plan**ned** |
| Наголос на останньому складі → подвоюємо | prefer → prefer**red**, admit → admit**ted** (але visit → visit**ed**) |
| BrE подвоює кінцеве **-l** | travel → travel**led** (AmE travel**ed**) |

**Вимова -ed:** `/t/` після глухих (*worked*), `/d/` після дзвінких і голосних (*played*), `/ɪd/` після **t / d** (*wanted, needed*).

## Типові помилки

- ✗ *Did you went?* → ✓ *Did you **go**?*
- ✗ *I buyed a car.* → ✓ *I **bought** a car.*
- ✗ *She didn't came.* → ✓ *She didn't **come**.*
- ✗ *They was at home.* → ✓ *They **were** at home.*
- ✗ *I have wrote* → ✓ *I have **written*** (після have — V3, а не V2)
