Кілька способів сказати, що вам **більше подобається**.

## Prefer (загальна перевага)

| Схема | Приклад |
| --- | --- |
| **prefer + іменник + to + іменник** | I **prefer** tea **to** coffee. |
| **prefer + -ing + to + -ing** | She **prefers** walking **to** driving. |
| **prefer to + V + rather than + V** | I **prefer to walk rather than take** the bus. |

`To` у першому й другому типі — **прийменник**, тож після нього іменник або -ing.

## Would prefer (перевага зараз)

| Схема | Приклад |
| --- | --- |
| **would prefer + to + V** | I'd **prefer to stay** home tonight. |
| **would prefer + іменник** | I'd **prefer** tea, please. |
| **would prefer + об'єкт + to + V** | I'd **prefer you to wait** outside. |
| **would prefer not to** | I'd **prefer not to** talk about it. |
| **would prefer + to V + rather than + V** | I'd prefer to **eat** out **rather than cook**. |

## Would rather, would sooner

Після них — **інфінітив без to**:

| Схема | Приклад |
| --- | --- |
| **would rather + V (+ than + V)** | I'd **rather stay** home **than go** out. |
| **would rather not + V** | I'd **rather not** go. |
| **would rather + підмет + Past Simple** | I'd **rather you stayed**. (хочу, щоб *ти*) |
| **would sooner** = would rather | I'd **sooner** walk than wait. |

## Швидке порівняння

| Загальна перевага | Перевага «зараз» |
| --- | --- |
| I **prefer** cats **to** dogs. | I'd **prefer** to have a cat. |
| I **like** walking **more than** driving. | I'd **rather walk** today. |

Див. також «Would rather (краще б)» і «Wish, if only, it's time».
