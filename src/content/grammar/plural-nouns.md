## A / an

Однина лічильних іменників зазвичай потребує `a / an` (див. «Артиклі»). У множині — без артикля: *a book → books*.

## Регулярна множина

| Правило | Приклад |
| --- | --- |
| Додаємо **-s** | book → book**s**, day → day**s** |
| Після **-s, -x, -ch, -sh, -z** → **-es** | bus → bus**es**, box → box**es**, watch → watch**es** |
| Приголосна + **y** → **-ies** | city → cit**ies**, baby → bab**ies** |
| Голосна + y → **-ys** | boy → boy**s** |
| Приголосна + **o** → **-es** (деякі) | tomato → tomato**es**, hero → hero**es** |
| **-f / -fe** → **-ves** (деякі) | leaf → lea**ves**, knife → kni**ves**, wife → wi**ves** |

**Вимова -s:** `/s/` після глухих (*books*), `/z/` після дзвінких (*days*), `/ɪz/` після шиплячих (*buses*).

## Неправильна множина

| Однина | Множина |
| --- | --- |
| man | **men** |
| woman | **women** |
| child | **children** |
| person | **people** |
| foot | **feet** |
| tooth | **teeth** |
| mouse | **mice** |
| sheep, fish, deer | **sheep, fish, deer** (без змін) |

## Лише множина

`trousers`, `jeans`, `glasses`, `scissors`, `clothes`, `people`, `police`: *My **trousers are** new.* Щоб сказати «одна пара»: *a pair of trousers*.

## Форма множини, але значення однини

`news`, `physics`, `mathematics`, `economics`: *The **news is** good.*

## Приклади

- *There are two **women** and three **children**.*
- *She has three **babies** and two **knives**.*

## Типові помилки

- ✗ *childs, mans, foots* → ✓ ***children, men, feet***
- ✗ *peoples* (люди) → ✓ ***people*** (*peoples* = народи)
- ✗ *The police is coming.* → ✓ *The police **are** coming.*
- ✗ *a trousers* → ✓ ***a pair of** trousers*
- ✗ *photoes* → ✓ ***photos*** (також *pianos, radios*)
