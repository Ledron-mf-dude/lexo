Обидва часи — про теперішнє, але дивляться на нього по-різному. **Present Simple** — те, що є **завжди, зазвичай, регулярно**. **Present Continuous** — те, що відбувається **саме зараз або тимчасово**.

> *I **work** in a bank, but this month I'**m working** from home.* — Я працюю в банку (постійно), але цього місяця працюю з дому (тимчасово).

## Present Simple: форма

| | Форма | Приклад |
| --- | --- | --- |
| Ствердження | V (для he / she / it — **+ s / es**) | She **works** in a bank. |
| Заперечення | do / does **+ not** + V | She **doesn't work** on Sundays. |
| Питання | **Do / Does** + підмет + V? | **Does** she **work** here? |
| Коротка відповідь | Yes, she **does**. / No, she **doesn't**. | |

Після `does` і `doesn't` дієслово повертається до **початкової форми** (без `-s`): *Does she **work**…?*, *He doesn't **like**…* Закінчення `-s` буває в реченні **один раз**.

## Закінчення 3-ї особи: -s, -es, -ies

| Правило | Приклади |
| --- | --- |
| Більшість дієслів: **+ s** | work → works, read → reads, play → plays |
| Після **-s, -ss, -sh, -ch, -x, -z, -o**: **+ es** | miss → misses, wash → washes, watch → watches, fix → fixes, go → goes, do → does |
| Приголосна + **y** → **-ies** | study → studies, try → tries, fly → flies |
| Голосна + y: просто **+ s** | play → plays, enjoy → enjoys |
| Неправильне | have → **has** |

**Вимова:** /s/ після глухих (*works, stops*), /z/ після дзвінких і голосних (*plays, reads*), /ɪz/ після шиплячих (*watches, washes*).

## Коли вживаємо Present Simple

| Значення | Приклад |
| --- | --- |
| Звички, регулярні дії | I **get up** at seven. / She **goes** to the gym twice a week. |
| Постійні ситуації | They **live** in Odesa. / He **works** as a designer. |
| Факти, загальні істини, закони природи | Water **boils** at 100°C. / The Earth **goes** round the Sun. |
| Розклади, програми (навіть про майбутнє) | The train **leaves** at 9.15. / The film **starts** at 8. |
| Стани, почуття, думки (stative verbs) | I **know** him. / She **loves** jazz. / I **think** you're right. |
| Інструкції, рецепти, вказівки | You **turn** left, then you **go** straight on. |
| Коментарі, заголовки, перекази сюжету | Messi **passes**, he **shoots**… / *In the film, a boy **finds** a dragon.* |

**Маркери:** `always`, `usually`, `often`, `sometimes`, `rarely / seldom`, `never`, `every day / week`, `on Mondays`, `in the morning(s)`, `once / twice a week`, `at weekends`.

## Прислівники частоти: де їх ставити

| Шкала | always → usually → often → sometimes → rarely / seldom → never |
| --- | --- |
| Приблизно | 100% → 90% → 70% → 50% → 10% → 0% |

| Правило | Приклад |
| --- | --- |
| **перед** основним дієсловом | She **usually walks** to work. |
| **після** `be` | He **is often** late. |
| **після** першого допоміжного чи модального | I **have never** been there. / You **can always** call me. |
| у короткій відповіді — **перед** допоміжним | "Do you cook?" — "Yes, I **always do**." / "No, I **never do**." |
| `sometimes`, `usually`, `often` можуть стояти й на початку | **Sometimes** I work late. |

`Rarely`, `seldom`, `never` уже заперечні, тому без `not`: *I **never** eat meat* (не *I don't never eat*). Питання про частоту — **How often…?**: *How often **do** you go there?* — *Twice a month.*

## Present Continuous: форма

| | Форма | Приклад |
| --- | --- | --- |
| Ствердження | am / is / are + **V-ing** | She **is working** now. |
| Заперечення | am / is / are **+ not** + V-ing | She **isn't working** now. |
| Питання | **Am / Is / Are** + підмет + V-ing? | **Is** she **working**? |
| Коротка відповідь | Yes, she **is**. / No, she **isn't**. | |

**Правопис -ing:**

| Правило | Приклади |
| --- | --- |
| Більшість: **+ ing** | work → working, play → playing |
| Німе **-e** зникає | make → making, write → writing (але see → seeing) |
| **-ie → -ying** | lie → lying, die → dying, tie → tying |
| Коротке слово на приголосна-голосна-приголосна: подвоюємо | sit → sitting, run → running, swim → swimming |
| Наголос на останньому складі — теж подвоюємо | begin → beginning, forget → forgetting (але visit → visiting) |
| BrE подвоює **-l** | travel → travelling (AmE traveling) |

## Коли вживаємо Present Continuous

| Значення | Приклад |
| --- | --- |
| Дія **саме зараз**, у момент мовлення | Be quiet! The baby **is sleeping**. |
| Дія **в цей період**, хоч і не цієї секунди | I**'m reading** a great book at the moment. (не просто зараз у руках) |
| **Тимчасова** ситуація | She**'s staying** with friends until she finds a flat. |
| **Зміни**, розвиток, тенденції | The climate **is getting** warmer. / Your English **is improving**. |
| **Домовленості** на майбутнє (час і місце відомі) | We**'re meeting** Tom at six tomorrow. (див. «Майбутнє: Present Continuous, be going to, Present Simple, Future Simple») |
| **always / constantly** + V-ing — роздратування, «вічно» | He**'s always losing** his keys! |

**Маркери:** `now`, `right now`, `at the moment`, `at present`, `currently`, `today`, `this week / month / year`, `these days`, `still`, `Look!`, `Listen!`

## Порівняння

| Present Simple | Present Continuous |
| --- | --- |
| Регулярно, звично | Прямо зараз, тимчасово |
| I **drink** coffee every morning. | I **am drinking** coffee now. |
| She **lives** in Kyiv. (постійно) | She **is living** in Kyiv this year. (тимчасово) |
| Water **boils** at 100°C. (факт) | The water **is boiling**. (зараз) |
| He **always forgets** my birthday. (просто факт) | He**'s always forgetting** my birthday! (дратує) |
| What **do** you **do**? — Яка у вас професія? | What **are** you **doing**? — Що ви робите зараз? |
| The bus **leaves** at 8. (розклад) | I**'m leaving** at 8. (мій план) |

## Дієслова стану

Дієслова, що означають **стан**, а не дію (`know`, `like`, `want`, `need`, `believe`, `own`, `belong`, `seem`…), зазвичай **не вживаються** в Continuous, навіть коли йдеться про «зараз»: *I **want** a coffee now* (не *I'm wanting*). Деякі мають два значення: *I **think** so* (вважаю) — *I'm **thinking** about it* (обмірковую). Повний перелік — у статті «Stative verbs і dynamic verbs».

Слова-підказки для всіх часів — у статті «Time markers».

## Типові помилки

- ✗ *She work in a bank.* → ✓ *She **works** in a bank.*
- ✗ *Look! It rains.* → ✓ *Look! **It's raining**.*
- ✗ *I am knowing the answer.* → ✓ *I **know** the answer.*
- ✗ *Does she works here?* → ✓ *Does she **work** here?*
- ✗ *I am usually get up at 7.* → ✓ *I usually **get** up at 7.*
- ✗ *He watchs TV every evening.* → ✓ *He **watches** TV every evening.*
- ✗ *She studys English.* → ✓ *She **studies** English.*
- ✗ *I don't never eat meat.* → ✓ *I **never** eat meat.*
- ✗ *She always is tired.* → ✓ *She **is always** tired.* (після be)
- ✗ *What do you do now?* (дія зараз) → ✓ *What **are** you **doing** now?*
- ✗ *I'm writting an email.* → ✓ *I'm **writing** an email.*
