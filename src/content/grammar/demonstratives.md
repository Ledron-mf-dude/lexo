## Форми

| | Близько (тут) | Далеко (там) |
| --- | --- | --- |
| **Однина** | **this** | **that** |
| **Множина** | **these** | **those** |

- ***This** book is mine.* / ***That** book is yours.*
- ***These** are my keys.* / ***Those** are hers.*

## Як частина мови

| Роль | Приклад |
| --- | --- |
| **Прикметник** (перед іменником) | I like **this** house. |
| **Займенник** (самостійно) | **This** is my sister. |

## Вживання

| Слово | Коли | Приклад |
| --- | --- | --- |
| **this / these** | ближче до говорячого; знайомство; теперішній момент | **This** is Anna. / I'm busy **this** week. |
| **that / those** | далі; уже згадане; минулий момент | Who's **that**? / I liked **that** film. |
| **that** у телефонній розмові | про співрозмовника | Who's **that**? |
| **this** у телефонній розмові | про себе | **This** is Tom speaking. |

## This чи it?

| This | It |
| --- | --- |
| Вказуємо на предмет, представляємо | Повторюємо вже названий предмет |
| **This** is my new phone. (показую) | **It** is very fast. (продовжуємо) |
| **This** is Anna. | **It's** cold today. (погода) |

`It` — для погоди, часу, відстані: *It's Monday. It's raining.*

## Сталі вирази

- *Like **that**! / Like **this**!* — ось так.
- *At **that** time* — тоді.
- *This week / this year* — цього тижня / цього року.
- ***That's** right. / **That's** all.*

## Типові помилки

- ✗ *This books are mine.* → ✓ ***These** books are mine.*
- ✗ *Those is my car.* → ✓ ***That** is my car.*
- ✗ *I'm busy that week.* (про поточний) → ✓ *I'm busy **this** week.*
- ✗ *This is raining.* → ✓ ***It** is raining.* (погода — it)
