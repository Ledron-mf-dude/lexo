Прийменники руху відповідають на питання **куди? звідки? як?**

## Основні

| Прийменник | Значення | Приклад |
| --- | --- | --- |
| **to** | до, у напрямку | I'm going **to** the shop. |
| **from** | з, від | She comes **from** Spain. |
| **into** | всередину | He walked **into** the room. |
| **out of** | з середини | She took the book **out of** the bag. |
| **onto** | на (поверхню) | The cat jumped **onto** the table. |
| **off** | з (поверхні) | He fell **off** the chair. |
| **up / down** | вгору / вниз | They ran **up** the stairs. |
| **towards** | у бік, до | He walked **towards** the door. |

## Через, повз, уздовж

| Прийменник | Значення | Приклад |
| --- | --- | --- |
| **through** | крізь (усередині) | The train goes **through** a tunnel. |
| **across** | поперек, через (по поверхні) | She swam **across** the river. |
| **along** | уздовж | We walked **along** the beach. |
| **past** | повз | He walked **past** the bank. |
| **over** | над, через | The plane flew **over** the mountains. |
| **under** | під | The path goes **under** the bridge. |
| **around / round** | навколо | They walked **around** the lake. |
| **round the corner** | за рогом | The shop is **round the corner**. |

## Транспорт

| Схема | Приклад |
| --- | --- |
| **get in / out of** (car, taxi) | She **got out of** the taxi. |
| **get on / off** (bus, train, plane) | I **got off** the bus. |
| **by** + транспорт | **by** car, **by** train, **by** plane |
| **on foot** | пішки |

## Arrive

- **arrive in** — місто, країна: *He arrived **in** Paris.*
- **arrive at** — місце, точка: *She arrived **at** the station.*
- **get to** / **reach** — без прийменника: *I got **to** the airport.* / *I reached the airport.*

## Home

Без `to`: *go **home**, come **home**, get **home***. Див. «Дієслово go».

## Ще прийменники руху

| Прийменник | Значення | Приклад |
| --- | --- | --- |
| **over** | через (зверху) | He jumped **over** the fence. |
| **under** | під (рух) | The cat ran **under** the bed. |
| **away from** | геть від | Move **away from** the door. |
| **back to** | назад до | Go **back to** your seat. |
| **out of** | з, із | Get **out of** the water! |
| **up / down** | угору / вниз | Walk **up** the hill. |

## Into чи in, onto чи on?

Після дієслів руху (*go, walk, run, jump, put*) зазвичай **into / onto**: *She jumped **into** the pool.* Але після `put`, `throw`, `fall` у розмові часто просто **in / on**: *Put it **in** the box.* Для місця без руху — лише **in / on**: *She's swimming **in** the pool.*

## Дієслова без прийменника

*enter* (не *enter into* про приміщення), *reach*, *leave* (покинути), *approach*: *We **reached** the top.* / *She **left** the room.*

## Типові помилки

- ✗ *I arrived to London.* → ✓ *I arrived **in** London.* (**at** the station)
- ✗ *go to home* → ✓ *go **home***
- ✗ *He went in the room.* (рух) → ✓ *He went **into** the room.*
- ✗ *get off the car* → ✓ *get **out of** the car* (але *get off the bus*)
- ✗ *The cat jumped in the table.* → ✓ *The cat jumped **onto** the table.* / *The cat jumped **on** the table.*
- ✗ *We reached to the station at six.* → ✓ *We **reached** the station at six.*
