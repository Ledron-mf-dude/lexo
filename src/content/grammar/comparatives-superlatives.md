## Утворення

| Тип прикметника | Порівняльний | Найвищий |
| --- | --- | --- |
| **Односкладові** | + **-er** | **the** + **-est** |
| | tall → tall**er** | tall → **the** tall**est** |
| **Довгі** (2+ склади) | **more** + adj | **the most** + adj |
| | **more** important | **the most** important |
| **-y (2 склади)** | -y → **-ier** | **the** -y → **-iest** |
| | happy → happ**ier** | happy → **the** happ**iest** |

## Правопис

| Правило | Приклад |
| --- | --- |
| Подвоюємо приголосну (CVC) | big → big**ger**, hot → hot**test** |
| -e → +r / +st | large → larg**er**, larg**est** |
| приголосна + y → -ier / -iest | busy → busier, busiest |

## Неправильні

| Звичайний | Порівняльний | Найвищий |
| --- | --- | --- |
| **good** | **better** | **the best** |
| **bad** | **worse** | **the worst** |
| **far** | **farther / further** | **the farthest / furthest** |
| **old** (у родині) | **elder** (+ іменник) | **the eldest** |
| **little** | **less** | **the least** |
| **much / many** | **more** | **the most** |

`Further` має ще й значення «додатковий, подальший»: ***further** information*, *until **further** notice*. `Elder / eldest` — лише про членів родини і лише перед іменником: *my **elder** sister*, але *She is **older** than me* (не *elder than*).

## Порівняння

- ***Than*** після порівняльного: *She is **taller than** me.* Після `than` у розмові — `me / him / her`; формальніше — з дієсловом: *…taller than **I am**.*
- **Найвищий ступінь:** ***the** oldest*, **in** (місце) / **of** (група): *the tallest **in** the class*, *the best **of** all*.
- **Менше:** *less expensive than*, *not as … as* — див. «As … as».

## Слова міри

*much / far / a lot / a bit / slightly* + порівняльний: *much bigger, a bit cheaper.* Див. «Порівняльний ступінь: a bit, a lot, much».

## Прислівники

| Тип | Порівняльний | Найвищий |
| --- | --- | --- |
| Односкладові (fast, hard) | fast**er** | **the** fast**est** |
| Прислівники на -ly | **more** carefully | **the most** carefully |

## Корисні шаблони

- *This is **the most interesting** book I've ever read.*
- *She is **one of the best** players in the team.*
- *It's getting **colder and colder**.* — усе холодніше.
- Двоскладові на -er, -le, -ow допускають обидві форми: *clever → cleverer / more clever*, *simple → simpler / more simple*.

## Типові помилки

- ✗ *more better* → ✓ ***better***
- ✗ *the most tallest* → ✓ ***the tallest***
- ✗ *She is taller that me.* → ✓ *…taller **than** me.*
- ✗ *the best in the world of* → ✓ *the best **in** the world* (in — місце, of — група: *the best of all*)
- ✗ *more easy* → ✓ ***easier*** (двоскладові на -y)
- ✗ *My brother is elder than me.* → ✓ *My brother is **older** than me.*
- ✗ *It's the more expensive hotel in the city.* → ✓ *It's **the most expensive** hotel in the city.*
- ✗ *She is the most intelligent of the class.* → ✓ *She is the most intelligent **in** the class.*
- ✗ *This is badder than before.* → ✓ *This is **worse** than before.*
