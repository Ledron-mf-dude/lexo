## Питання до підмета

Коли питальне слово **саме є підметом**, `do / does / did` **не потрібне**: порядок слів як у ствердженні.

| Ствердження | Питання до підмета |
| --- | --- |
| **Tom** called. | **Who called**? (не *Who did call?*) |
| **Something** happened. | **What happened**? |
| **Anna** lives here. | **Who lives** here? |
| **Three people** came. | **How many people came**? |
| **Someone** is knocking. | **Who is knocking**? |

## Питання до додатка

Тут потрібне допоміжне:

| Питання | Приклад |
| --- | --- |
| **Who / what + do/does/did + підмет + V?** | **Who did** Tom **call**? |
| | **What does** she **want**? |

## Порівняння

| До підмета | До додатка |
| --- | --- |
| **Who** called Tom? (хто дзвонив) | **Who** did Tom call? (кому дзвонив) |
| **What** happened? | **What** did you see? |
| **Who** loves Anna? | **Who** does Anna love? |

## Питання з прийменником

Прийменник зазвичай іде **в кінець** питання:

- ***Who** did you go **with**?*
- ***What** are you looking **at**?*
- ***Where** do you come **from**?*
- ***Who** is she talking **to**?*

У формальному мовленні прийменник — на початку: ***With whom** did you go?* / ***To whom** are you talking?*

## Дієслово після who / what — в однині

- ***Who** knows the answer?* — однина: *Who **knows**?* (не *know*)
- ***What** makes you happy?* — підмет.

## Запам'ятайте

1. Питальне слово — **підмет** → просто дієслово: ***Who** phoned?*
2. Питальне слово — **додаток** → допоміжне + підмет + дієслово: ***Who** did you phone?*

## Which і whose до підмета

- ***Which** team **won**?* (не *Which team did win?*)
- ***Whose** phone **is ringing**?*
- ***How many** people **came**?*

## Питання з прийменником до підмета

Якщо питаємо про підмет, а прийменник належить додатку: ***Who** lives **with** you?* — хто живе з тобою (підмет). ***Who** do you live **with**?* — з ким ти живеш (додаток).

## Короткі питання-реакції

*"Somebody called." — "**Who?**"* / *"Something happened." — "**What?**"* / *"I met someone." — "**Who did you meet?**"*

## Як вибрати

1. Питаєте про **підмет** (хто? що? зробив) — без *do / does / did*, дієслово як у ствердженні: *Who called you?*
2. Питаєте про **додаток** (кого? що? зробив він) — з допоміжним: *Who did you call?*
3. Щоб розрізнити, дайте відповідь: *Tom called me* → питання до *Tom* (підмет) — *Who called?*
4. Прийменник у питанні до додатка — у кінці: *Who did you go with?*

## Пастки перекладу

- «Хто тобі дзвонив?» — *Who called you?*, а не *Who did call you?*
- «Що сталося?» — *What happened?*, без *did*.
- «Скільки людей прийшло?» — *How many people came?*
- «З ким ти живеш?» — *Who do you live with?*

## Типові помилки

- ✗ *Who did call you?* → ✓ ***Who called** you?*
- ✗ *What did happen?* → ✓ ***What happened**?*
- ✗ *Who know the answer?* → ✓ *Who **knows** the answer?*
- ✗ *Who you are talking to?* → ✓ *Who **are you** talking to?*
- ✗ *Which team did win the match?* → ✓ *Which team **won** the match?*
- ✗ *Whose phone does ring?* → ✓ *Whose phone **is ringing**?*
