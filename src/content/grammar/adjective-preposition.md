Багато прикметників вживаються з **певним прийменником**.

## Таблиця

| Прийменник | Прикметники |
| --- | --- |
| **of** | afraid **of**, proud **of**, tired **of**, jealous **of**, capable **of**, aware **of**, fond **of**, scared **of**, full **of** |
| **at** | good **at**, bad **at**, brilliant **at**, surprised **at** |
| **in** | interested **in**, disappointed **in**, involved **in** |
| **about** | worried **about**, excited **about**, angry **about**, nervous **about**, sorry **about** |
| **with** | angry **with**, bored **with**, pleased **with**, satisfied **with**, happy **with**, familiar **with** |
| **for** | famous **for**, responsible **for**, ready **for**, sorry **for**, late **for** |
| **to** | married **to**, similar **to**, kind **to**, allergic **to**, addicted **to**, engaged **to** |
| **on** | keen **on**, dependent **on**, based **on** |
| **from** | different **from**, safe **from** |

## Приклади

- *She is **afraid of** spiders.* / *I'm **proud of** you.*
- *He's **good at** maths.* / *She's **bad at** cooking.*
- *We're **interested in** history.*
- *I'm **worried about** the exam.*
- *Are you **angry with** me?* / *She's **angry about** the delay.*
- *He is **married to** Anna.*
- *This is **similar to** that.* / *This is **different from** that.*

## Різні прийменники — різні значення

| Прикметник | З ким / чим | З чого |
| --- | --- | --- |
| **angry** | **with** a person | **about / at** a thing |
| **sorry** | **for** a person's suffering: *I'm sorry **for** him.* | **about** situation: *I'm sorry **about** the mess.* |
| **surprised** | **at / by** | — |

## Після прийменника

Далі йдуть **іменник, займенник або gerund**: *afraid **of flying***, *good **at drawing***, *interested **in learning***.

## Особливий випадок: of + людина

- ***It was kind of** you to help.* (характеристика)
- ***Nice / kind / rude / clever / silly of** someone **to** do…*

## Порівняйте

*She is **good at** tennis* (уміє) — *She is **good for** you* (корисно) — *She is **good to** me* (добра до мене).

## Типові помилки

- ✗ *I'm interested about history.* → ✓ *I'm interested **in** history.*
- ✗ *She is good in maths.* → ✓ *She is good **at** maths.*
- ✗ *He is married with Anna.* → ✓ *He is married **to** Anna.*
- ✗ *I'm afraid from dogs.* → ✓ *I'm afraid **of** dogs.*
- ✗ *different than* (BrE вважає розмовним) → ✓ *different **from***

Див. «Дієслово + прийменник» і «Gerund».
