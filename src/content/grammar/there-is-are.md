`There is / there are` — щоб сказати, що щось **існує чи знаходиться** десь. Підмет — іменник **після** дієслова.

## Форми

| Час | Однина / нелічильне | Множина |
| --- | --- | --- |
| **Present** | There **is** a book. | There **are** two books. |
| **Past** | There **was** a problem. | There **were** many people. |
| **Present Perfect** | There **has been** an accident. | There **have been** changes. |
| **Future** | There **will be** a meeting. | There **will be** guests. |
| **Модальні** | There **might be** a problem. | There **must be** mistakes. |

## Заперечення та питання

- ***There isn't** any milk.* / ***There aren't** any seats.*
- ***Is there** a bank near here?* — Yes, **there is**. / No, **there isn't**.
- ***Are there** any questions?* — Yes, **there are**.
- ***How many** students **are there**?*

`Some` — у ствердженні, `any` — у запереченні й питаннях; для нелічильних: ***There is some** water.*

## Узгодження

Дієслово погоджується з **першим** іменником після нього:

- *There **is** a book and two pens.*
- *There **are** two pens and a book.*

У розмові вживають `there's` і з множиною: *There's two men outside.*

## There is going to be

- *There **is going to be** a storm.* — Буде буря (є ознаки).

## Сталі вирази

- ***There is no need** to worry.*
- ***There is no point in** arguing.* (див. «Gerund»)
- ***There used to be** a cinema here.* — Раніше тут було кіно.
- ***There seems to be** a mistake.* — Здається, є помилка.

## Типові помилки

- ✗ *There are a book on the table.* → ✓ *There **is** a book…*
- ✗ *It is a cat in the garden.* → ✓ ***There is** a cat in the garden.*
- ✗ *Is there any questions?* → ✓ ***Are** there any questions?*
- ✗ *In the room is a table.* (калька) → ✓ ***There is** a table in the room.*
- ✗ *There will a meeting.* → ✓ *There will **be** a meeting.*

Порівняйте з `it`: «There чи it».
