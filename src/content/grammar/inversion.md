**Інверсія** — коли **допоміжне дієслово стоїть перед підметом**. Використовується в формальному й літературному стилі для **виразності**.

## Після заперечних прислівників

Заперечне слово на початку → **допоміжне + підмет + основне дієслово**:

| Звичайна форма | З інверсією |
| --- | --- |
| I have **never** seen such a thing. | **Never have I** seen such a thing. |
| She **rarely** goes out. | **Rarely does she** go out. |
| He **seldom** complained. | **Seldom did he** complain. |
| I **little** knew what was coming. | **Little did I** know what was coming. |

## Списки слів

| Слова | Приклад |
| --- | --- |
| **never, rarely, seldom, little** | **Never** have I been so happy. |
| **hardly … when / scarcely … when** | **Hardly had** I arrived **when** it started to rain. |
| **no sooner … than** | **No sooner had** she left **than** he called. |
| **not only … but also** | **Not only did** he win, **but** he **also** broke the record. |
| **only + час / умова** | **Only then did** I understand. / **Only after** the exam **did** I relax. |
| **not until** | **Not until** midnight **did** they arrive. |
| **under no circumstances / at no time / in no way** | **Under no circumstances** should you open it. |

## So / such на початку

- ***So beautiful was** the view **that** we stayed.* (= The view was so beautiful that…)
- ***Such was** his anger **that** he left.*

## Умовні речення

Формальні: ***Had I** known, I'd have called.* / ***Should you** need help, call me.* / ***Were she** here, she'd agree.* Див. «Умовні речення: unless, provided, otherwise, інверсія».

## Місце: Here / There

- ***Here comes** the bus!* / ***There goes** my chance.* (з іменником; з займенником — прямий порядок: *Here it comes*)

## Пам'ятка

1. Немає допоміжного? Додаємо **do / does / did**: *Never **did** I see…*
2. Речення залишається ствердним: *Never **have I** seen*, не *haven't*.
3. Вживайте обережно: це ефектно, але **формально**.
