Основи — у «Contrast, purpose, reason, result (although, so that, because of, therefore)» і «Умовні речення: unless, provided, otherwise, інверсія». Тут — сполучники, які роблять текст точнішим і формальнішим. Важливо знати, **що** стоїть після кожного: речення, іменник чи *-ing*.

## Причина

| Слово | Після нього | Приклад |
| --- | --- | --- |
| **given that** | речення | ***Given that** he's new, he did well.* |
| **given** | іменник | ***Given** the weather, we stayed in.* |
| **seeing that / seeing as** (розмовне) | речення | ***Seeing as** you're here, you can help.* |
| **now that** | речення | ***Now that** we have a car, we travel more.* — тепер, коли |
| **in that** | речення | *The plan is risky **in that** it depends on one client.* — тим, що |

## Умова

- **provided / providing (that), as long as, on condition that** — «за умови, що»; після них — **теперішній** час про майбутнє: *You can borrow it **provided** you **bring** it back.*
- **in the event of** + іменник / **in the event that** + речення — «у разі»: ***In the event of** fire, use the stairs.*
- **assuming (that), supposing** — «припустімо, що»: ***Assuming** the train is on time, we'll be there by six.*

## Поступка

- **albeit** — книжне «хоча й»; після нього **не** речення, а прикметник, прислівник чи іменна група: *a small, **albeit** important, change* / *He agreed, **albeit** reluctantly.*
- **much as** + речення — «хоч як (сильно)»: ***Much as** I like him, I can't lend him money.*
- **for all** + іменник — «попри весь»: ***For all** his money, he isn't happy.*
- **granted (that), admittedly** — «визнаю, що»: ***Granted**, it's expensive, but it's worth it.*

## Мета

- **so as to / so as not to** + V: *I left early **so as not to** miss the train.* (не ~~*so as to not*~~ у старанному стилі)
- **in order that** + речення з *can / could / may*: *She spoke slowly **in order that** everyone **could** follow.*
- **for fear of** + *-ing* / **for fear (that)** + речення — «щоб не, боячись»: *He didn't move **for fear of waking** the baby.*

## Наслідок і межі

- **hence** + іменник, **thus / consequently** + речення — «звідси, отже»: *The roads were icy, **hence** the delay.* / *…; **thus**, we had to wait.*
- **insofar as / in so far as** — «наскільки, оскільки»: *I'll help **insofar as** I can.*
- **as far as** X **is concerned** — «що стосується X»: ***As far as** money **is concerned**, we're fine.*

## Як вибрати

1. Причина + речення — *given that, now that, in that*; причина + іменник — *given*.
2. Умова — *provided / as long as / on condition that* + теперішній час.
3. «Хоча й» перед прикметником чи прислівником — *albeit*; перед реченням — *although*.
4. Мета із запереченням — *so as not to* + V; «боячись» — *for fear of* + *-ing*.
5. «Звідси» + іменник — *hence*; + речення — *thus / consequently*.

## Пастки перекладу

- «Зважаючи на те, що…» — *given that…*; «зважаючи на погоду» — *given the weather*.
- «За умови, що ти повернеш» — *provided you **return***, не *will return*.
- «Хоча й неохоче» — *albeit reluctantly*.
- «Що стосується мене» — *as far as I'm concerned*.

## Типові помилки

- ✗ *He accepted the offer, albeit he wasn't happy about it.* → ✓ *He accepted the offer, **although** he wasn't happy about it.* / *He accepted the offer, albeit **unhappily**.*
- ✗ *You can use my car provided you will drive carefully.* → ✓ *You can use my car provided you **drive** carefully.*
- ✗ *I spoke quietly so as to not wake anyone.* → ✓ *I spoke quietly **so as not to** wake anyone.*
- ✗ *She didn't say anything for fear to upset him.* → ✓ *She didn't say anything for fear **of upsetting** him.*
- ✗ *Now when we have a car, we can travel much more.* → ✓ *Now **that** we have a car, we can travel much more.*
- ✗ *As far as money concerned, we have no problems.* → ✓ *As far as money **is concerned**, we have no problems.*
