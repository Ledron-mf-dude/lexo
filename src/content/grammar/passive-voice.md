У пасивному стані підметом є той, **над ким виконується дія**. Використовуємо його, коли важливіша сама дія чи її результат, а не той, хто її виконав.

> *They build many houses every year.* → *Many houses **are built** every year.*

## Формула

**Subject + to be (у потрібному часі) + V3** (Verb + -ed / третя форма).

Змінюється лише дієслово `to be` — за ним видно час. Змістове дієслово завжди в третій формі.

## Усі часи

| Час | Форма | Приклад |
| --- | --- | --- |
| **Present Simple** | am / is / are + V3 | Many houses **are built** every year. |
| **Present Continuous** | am / is / are + **being** + V3 | Many houses **are being built** now. |
| **Present Perfect** | have / has + **been** + V3 | Many houses **have been built** this year. |
| **Past Simple** | was / were + V3 | Many houses **were built** last year. |
| **Past Continuous** | was / were + **being** + V3 | Many houses **were being built** in this neighbourhood when I moved here. |
| **Past Perfect** | had + **been** + V3 | Many houses **had been built** in this neighbourhood before I moved here. |
| **Future Simple** | will + **be** + V3 | Many houses **will be built** in this neighbourhood next year. |
| **Future Perfect** | will have + **been** + V3 | Many houses **will have been built** in this neighbourhood by 2030. |

## Як запам'ятати

- **Simple** — просто `to be` у потрібному часі: *are built, were built, will be built*.
- **Continuous** — додається **being**: *are being built, were being built*.
- **Perfect** — додається **been**: *have been built, had been built, will have been built*.

## Активний → пасивний

| Active | Passive |
| --- | --- |
| They **built** these houses last year. | These houses **were built** last year. |
| Someone **is repairing** the road now. | The road **is being repaired** now. |
| They **have finished** the project. | The project **has been finished**. |

Виконавця можна додати через `by`, якщо він важливий: *The house was built **by a famous architect**.*

> Не плутайте: після `be` у пасиві — **третя форма**, а не -ing. *The road is being repaired* — тут `being` — частина форми Continuous.
