Від одного кореня англійська утворює іменник, дієслово, прикметник і прислівник: *decide → decision → decisive → decisively*. Знаючи типові **суфікси** (змінюють частину мови) і **префікси** (змінюють значення), можна вгадати незнайоме слово й не помилитися з формою в тесті.

## Як визначити, яке слово потрібне

Подивіться на **місце в реченні**:

| Місце | Потрібна частина мови | Приклад |
| --- | --- | --- |
| після артикля, `my`, прикметника; перед дієсловом як підмет | **іменник** | The **decision** was hard. |
| після підмета, після `to`, після модального | **дієслово** | We need to **decide**. |
| перед іменником; після `be`, `seem`, `look` | **прикметник** | It was a **decisive** moment. |
| біля дієслова, перед прикметником | **прислівник** | She acted **decisively**. |

Далі перевірте **зміст**: чи потрібне заперечення (*un-*, *-less*), множина, особа (*-er*) або річ (*-ment*).

## Суфікси іменників

| Суфікс | Від чого | Приклади |
| --- | --- | --- |
| **-tion / -sion / -ation** | дієслово → дія, процес | inform → information, decide → decision, organise → organisation |
| **-ment** | дієслово → дія, результат | develop → development, agree → agreement, pay → payment |
| **-ness** | прикметник → якість | kind → kindness, happy → happiness, dark → darkness |
| **-ity** | прикметник → якість | possible → possibility, real → reality, active → activity |
| **-ance / -ence** | дієслово, прикметник → стан | perform → performance, differ → difference, patient → patience |
| **-ure** | дієслово → дія, результат | fail → failure, press → pressure, close → closure |
| **-ship / -hood** | іменник → стосунок, стан | friend → friendship, child → childhood, neighbour → neighbourhood |
| **-dom** | стан, сфера | free → freedom, bore → boredom |
| **-th** | прикметник → вимір | long → length, wide → width, strong → strength, deep → depth |

## Іменники-люди

| Суфікс | Приклади |
| --- | --- |
| **-er** | teach → teacher, drive → driver, employ → employer (той, хто наймає) |
| **-or** | act → actor, direct → director, visit → visitor |
| **-ist** | art → artist, science → scientist, journal → journalist |
| **-ian** | music → musician, library → librarian, politics → politician |
| **-ant / -ent** | assist → assistant, apply → applicant, study → student |
| **-ee** | employ → employee (той, кого наймають), train → trainee |

## Суфікси прикметників

| Суфікс | Значення | Приклади |
| --- | --- | --- |
| **-ful** | має, сповнений | use → useful, care → careful, help → helpful |
| **-less** | без | use → useless, care → careless, home → homeless |
| **-able / -ible** | можна зробити, здатний | wash → washable, afford → affordable, response → responsible |
| **-ous** | має якість | danger → dangerous, fame → famous, nerve → nervous |
| **-ive** | має схильність | create → creative, attract → attractive, expense → expensive |
| **-al** | пов'язаний із | nation → national, music → musical, culture → cultural |
| **-y** | має, схожий | rain → rainy, health → healthy, noise → noisy |
| **-ic** | пов'язаний із | science → scientific, economy → economic, history → historic |
| **-ly** (від іменника) | характерний для | friend → friendly, day → daily, cost → costly |
| **-ed / -ing** | почуття / причина | bored — boring (див. «Прикметники на -ed і -ing: bored чи boring») |

`-ful` і `-less` часто утворюють пару-протилежність: *useful — useless*, *careful — careless*, *hopeful — hopeless*. Але не завжди: є *priceless* (безцінний, дуже цінний), а *priceful* немає.

## Суфікси дієслів

| Суфікс | Приклади |
| --- | --- |
| **-ise / -ize** | modern → modernise, critic → criticise, real → realise (BrE -ise, AmE -ize) |
| **-ify** | simple → simplify, class → classify, just → justify |
| **-en** | short → shorten, wide → widen, strength → strengthen |
| **en- / em-** (префікс) | able → enable, courage → encourage, power → empower |

## Прислівники

Найчастіше **прикметник + -ly**: *careful → carefully*, *easy → easily*, *basic → basically*. Правила й винятки (*good → well*, *hard → hard*) — у статті «Прикметники й прислівники: slow чи slowly».

## Префікси із запереченням

| Префікс | Де вживається | Приклади |
| --- | --- | --- |
| **un-** | найпоширеніший | unhappy, unusual, unable, unlock, unemployed |
| **in-** | переважно латинські корені | incorrect, independent, informal, invisible |
| **im-** | перед **m, p** | impossible, impatient, immature, impolite |
| **il-** | перед **l** | illegal, illogical, illiterate |
| **ir-** | перед **r** | irregular, irresponsible, irrelevant |
| **dis-** | протилежна дія чи якість | disagree, dislike, dishonest, disappear |
| **non-** | «не-», нейтрально | non-smoker, non-fiction, non-stop |

Точного правила, коли `un-`, а коли `in-`, немає: перевіряйте в словнику. Але `im-`, `il-`, `ir-` підказує перша літера кореня.

## Інші префікси

| Префікс | Значення | Приклади |
| --- | --- | --- |
| **re-** | знову | rewrite, rebuild, reconsider |
| **mis-** | неправильно | misunderstand, misspell, mislead |
| **over- / under-** | надто / недостатньо | overcook, overestimate / underpaid, underestimate |
| **pre- / post-** | до / після | prepay, preview / postpone, post-war |
| **co-** | разом | co-worker, co-operate, co-author |
| **anti-** | проти | antisocial, antivirus |
| **multi- / bi-** | багато / два | multicultural / bilingual, bicycle |
| **ex-** | колишній | ex-wife, ex-president |
| **self-** | сам | self-confident, self-employed |

## Зміни в написанні

- Кінцеве **-e** зникає перед голосним суфіксом: *create → creation, creative*; але лишається перед приголосним: *care → careful*.
- **-y → -i** після приголосної: *happy → happiness*, *beauty → beautiful*, *busy → business*.
- Подвоєння приголосної: *begin → beginner*, *forget → forgettable*.
- Деякі корені змінюються: *explain → explanation*, *pronounce → pronunciation*, *deep → depth*, *high → height*.

## Типові помилки

- ✗ *He gave me a good advise.* → ✓ *He gave me some good **advice**.* (advise — дієслово, advice — іменник)
- ✗ *It's unpossible.* → ✓ *It's **impossible**.* (перед p — im-)
- ✗ *She is very responsable.* → ✓ *She is very **responsible**.*
- ✗ *Thank you for your helpness.* → ✓ *Thank you for your **help**.*
- ✗ *The pronounciation is hard.* → ✓ *The **pronunciation** is hard.* (у іменнику немає -o-)
- ✗ *He is unpatient.* → ✓ *He is **impatient**.*
- ✗ *I disagree with the employee who hired me.* → ✓ *I disagree with the **employer** who hired me.* (employer наймає, employee — найманий)
