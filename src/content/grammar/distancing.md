**Distancing** (або **hedging**) — способи сказати щось **обережно**: не беручи повної відповідальності за факт, пом'якшуючи категоричність. Так пишуть новини, звіти, наукові тексти; так ввічливо говорять на роботі.

## Інструменти

| Засіб | Приклад | Відтінок |
| --- | --- | --- |
| **seem / appear** | The plan **seems to be** working. | здається |
| **It seems / appears that** | **It appears that** the data is wrong. | схоже, що |
| **Пасив з reporting verbs** | He **is said to be** very rich. / **It is believed that**… | кажуть, вважають |
| **Прислівники** | **Apparently**, she's leaving. / The man **allegedly** stole it. | нібито, як кажуть |
| **According to** | **According to** the report, prices will rise. | за даними |
| **tend to** | Young people **tend to** use social media more. | зазвичай, мають тенденцію |
| **Модальні** | This **may / might / could** be the reason. | можливо |
| **Пом'якшувачі** | **Perhaps** / **It's possible that** / **to some extent** | певною мірою |

## Пасив з reporting verbs

| Схема | Приклад |
| --- | --- |
| **It is said / thought / believed / reported that** + речення | **It is reported that** two people were injured. |
| **Підмет + is said to + V** | The company **is thought to be** in trouble. |
| **Підмет + is said to have + V3** (минуле) | The painting **is believed to have been** stolen in 1990. |

Детальніше: «Passive: it is said that…, have something done».

## Apparently, allegedly, supposedly

- ***Apparently**, the meeting has been cancelled.* — Кажуть / схоже, зустріч скасували (я чув).
- *The suspect **allegedly** broke into the house.* — нібито (не доведено, мова юристів і новин).
- *This is **supposedly** the best restaurant in town.* — нібито (з сумнівом).

## Ввічливо на роботі

Замість категоричного *Your report is wrong* — м'якше:

- *There **seem to be** a few mistakes in the report.*
- ***I'm not sure**, but **I think** the figures **might** need checking.*
- ***It would appear that** we're over budget.*

Див. також «Seem — здаватися» і «Likely, unlikely, bound, definitely, probably».

## Пом'якшення в діловому листуванні

| Різко | М'якше |
| --- | --- |
| You made a mistake. | **There seems to be** a mistake. |
| This is wrong. | This **might not be quite** right. |
| We can't do it. | **I'm afraid** we **won't be able to** do it. |
| Send it today. | **Would it be possible to** send it today? |
| I disagree. | **I'm not sure I** agree. / **I see your point, but**… |

## Слова-пом'якшувачі

*slightly, a bit, somewhat, rather, quite, fairly, to some extent, in a way, sort of (розм.)*: *The results are **somewhat** disappointing.* / *I'm **a bit** worried.*

## Як вибрати

1. Хочете не брати відповідальність за інформацію? — *apparently, allegedly, it seems / appears that…*
2. Посилаєтеся на джерело? — *according to* + джерело (не про себе).
3. Пишете новину чи звіт? — пасив: *It is said / reported / believed that…* або *He is said to be…*
4. Подія в минулому в такій конструкції — перфектний інфінітив: *is reported to have resigned*.
5. Хочете м'яко сказати неприємне — *There seems to be a problem*, *I'm afraid…*, *tend to*.

## Пастки перекладу

- «На мою думку» — *In my opinion*, не *According to me*.
- «Кажуть, що він багатий» — *He is said to be rich* або *It is said that he is rich*; *He is said that* — помилка.
- «Здається, є помилка» — *There seems to be a mistake*.
- Українське «нібито» у новинах — *allegedly*.

## Типові помилки

- ✗ *He is said that he is rich.* → ✓ *He is said **to be** rich.* / ***It** is said that he is rich.*
- ✗ *It seems that he to be busy.* → ✓ *It seems that he **is** busy.* / *He seems **to be** busy.*
- ✗ *According to me, it's wrong.* → ✓ ***In my opinion**, it's wrong.* (according to — про джерело, не про себе)
- ✗ *People tend using phones.* → ✓ *People tend **to use** phones.*
- ✗ *It seems that there is a mistake to be.* → ✓ *There **seems to be** a mistake.* / *It seems that there is a mistake.*
- ✗ *Would it be possible sending it today?* → ✓ *Would it be possible **to send** it today?*
