Три схожих конструкції, які легко сплутати.

| Конструкція | Значення | Що далі | Приклад |
| --- | --- | --- | --- |
| **used to** | **колись було так** (тепер уже ні) | інфінітив | I **used to smoke**. — Раніше я курив. |
| **would** | колись **регулярно** робив | інфінітив | Every summer we **would visit** my grandma. |
| **be used to** | **звик**, для мене це звично | іменник або **-ing** | I'**m used to** getting up early. |
| **get used to** | **звикаю / звикну** | іменник або **-ing** | I'm **getting used to** the noise. |

## Used to

- Для **звичок і станів** у минулому: *She **used to live** in Paris.*
- Заперечення й питання: *I **didn't use to** like coffee.* / *Did you **use to** play chess?* (у цих формах `used` → `use`).

## Would для минулих звичок

- Тільки **повторювані дії**, не стани: *We **would play** outside all day.*
- Про стани — лише `used to`: *I **used to have** a dog.* (не *I would have a dog*)

## Be / get used to

`To` тут — **прийменник**, тож після нього іменник або gerund:

- *He **is used to** the cold.* / *He **is used to** living alone.*
- *It takes time to **get used to** a new job.*

> Порівняйте: *I **used to** work nights* (раніше працював) — *I'**m used to** working nights* (звик працювати вночі).

## Про теперішнє — без used to

Для звичок **зараз** `used to` не вживається. Беремо Present Simple з `usually`: *I **usually** get up at 7* (не *I use to get up*).

## Заперечення й питання

| | Приклад |
| --- | --- |
| Заперечення | I **didn't use to** like coffee. / I **never used to** like coffee. |
| Питання | **Did** you **use to** play chess? |
| Коротка відповідь | Yes, I **did**. / No, I **didn't**. |

Вимова: **used to** /ˈjuːs tə/ — з глухим /s/, на відміну від *used* /juːzd/ («використаний»).

## Be used to і get used to в усіх часах

`Be used to` і `get used to` змінюються за часами, як звичайні дієслова:

- *I **was used to** the noise.* — Я вже звик до шуму (тоді).
- *You'**ll get used to** it.* — Ти звикнеш.
- *She **has got used to** working at night.* — Вона вже звикла працювати вночі.
- *I'**m getting used to** my new job.* — Поступово звикаю.

## Колись так, тепер ні

Щоб підкреслити зміну, `used to` часто поєднують із **any more / no longer**: *I used to live in Kharkiv, but I **don't** live there **any more**.* Див. «No longer, any longer, anymore».

## Типові помилки

- ✗ *I use to smoke.* (у минулому) → ✓ *I **used to** smoke.*
- ✗ *Did you used to play chess?* → ✓ *Did you **use to** play chess?*
- ✗ *I'm used to get up early.* → ✓ *I'm used to **getting** up early.*
- ✗ *When I was a child, I would have a dog.* (стан, не повторювана дія) → ✓ *When I was a child, I **used to have** a dog.*
- ✗ *I use to get up at 7 every day.* → ✓ *I **usually get** up at 7 every day.* / *I used to get up at 7 every day.*
- ✗ *She is used to live alone.* → ✓ *She is used to **living** alone.*
- ✗ *I'll never get used to drive on the left.* → ✓ *I'll never get used to **driving** on the left.*
