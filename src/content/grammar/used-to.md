Три схожих конструкції, які легко сплутати.

| Конструкція | Значення | Що далі | Приклад |
| --- | --- | --- | --- |
| **used to** | **колись було так** (тепер уже ні) | інфінітив | I **used to smoke**. — Раніше я курив. |
| **would** | колись **регулярно** робив | інфінітив | Every summer we **would visit** my grandma. |
| **be used to** | **звик**, для мене це звично | іменник або **-ing** | I'**m used to** getting up early. |
| **get used to** | **звикаю / звикну** | іменник або **-ing** | I'm **getting used to** the noise. |

## Used to

- Для **звичок і станів** у минулому: *She **used to live** in Paris.*
- Заперечення й питання: *I **didn't use to** like coffee.* / *Did you **use to** play chess?* (у цих формах `used` → `use`).

## Would для минулих звичок

- Тільки **повторювані дії**, не стани: *We **would play** outside all day.*
- Про стани — лише `used to`: *I **used to have** a dog.* (не *I would have a dog*)

## Be / get used to

`To` тут — **прийменник**, тож після нього іменник або gerund:

- *He **is used to** the cold.* / *He **is used to** living alone.*
- *It takes time to **get used to** a new job.*

> Порівняйте: *I **used to** work nights* (раніше працював) — *I'**m used to** working nights* (звик працювати вночі).

## Типові помилки

- ✗ *I use to smoke.* (у минулому) → ✓ *I **used to** smoke.*
- ✗ *Did you used to play chess?* → ✓ *Did you **use to** play chess?*
- ✗ *I'm used to get up early.* → ✓ *I'm used to **getting** up early.*
- ✗ *I would have a dog.* (стан) → ✓ *I **used to** have a dog.*
